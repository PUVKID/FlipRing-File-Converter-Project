# OCR 구성요소와 소스

플립링의 OCR은 Tesseract를 별도 프로세스로 실행합니다. PUVKID가 OCR 엔진의 원저작자라고 주장하지 않습니다.
Tesseract 5.5.3.20260724 공식 Windows 실행 파일과 필요한 DLL만 원본 그대로 동봉합니다. 별도 관리자 설치는 필요하지 않습니다.
Tesseract 자체의 Apache-2.0 원문은 vendor/tesseract/doc/LICENSE에 있고 원본 저자 목록도 같은 doc에 있습니다.
libjbig의 원본 소스 jbig.c는 GPL 버전 2 또는 이후 버전 선택을 허용합니다. 이 OCR 결합 구성의 배포에는 GPL 버전 3을 선택하며 GPL-3.0.txt를 동봉합니다. Apache-2.0과 각 의존성의 원문 고지도 그대로 유지합니다.
플립링의 별도 Python/Qt 프로그램과 OCR 프로세스는 별개이며 각 부분의 고지는 함께 제공됩니다. 이 설명이 구성요소 원문 라이선스를 대체하지 않습니다.

MSYS2-구성요소.json에는 DLL과 정확히 SHA-256이 일치한 25개 MSYS2 바이너리 패키지, 버전, 라이선스, 원본 패키지 URL, 전체 소스 아카이브 URL과 해시를 기록했습니다.
giflib 5.2.2와 libjpeg-turbo 3.1.3은 Tesseract가 선언한 버전과 동일한 원본 고지·소스를 보존했습니다. 이 두 허용 라이선스 패키지의 바이너리 해시가 동일하다는 검증은 하지 못했습니다.
각 패키지 폴더의 원문 고지와 PKGINFO.txt, sources의 .src.tar.zst에는 원본 소스·패치·PKGBUILD·.SRCINFO가 있습니다. 바이너리만 제공하는 원격 링크 안내로 대체하지 않습니다.
GCC 런타임 두 DLL의 별도 소스·고지·대응 기록은 ubuntu-gcc 폴더에 보관합니다.

## 빌드와 교체

Tesseract 전체 소스는 sources/tesseract-5.5.3.tar.gz에 있습니다. 해당 소스의 nsis/build.sh와 .github/workflows/installer-for-windows.yml이 공식 Windows 빌드 절차이며 Ubuntu 24.04에서 MinGW64를 사용합니다.
이 절차는 처음 작성 당시 현재 MSYS2 저장소를 조회하므로 역사적 의존성을 재현할 때에는 구성요소 목록의 정확한 .src.tar.zst·PKGBUILD·패치를 사용해야 합니다.
MSYS2 소스 묶음은 MSYS2 환경에서 풀어 PKGBUILD의 makepkg-mingw 절차로 빌드할 수 있습니다. gcc 런타임은 ubuntu-gcc의 원본 패키지 빌드 안내를 따릅니다.
라이브러리와 실행 파일은 동적으로 분리되어 있습니다. 해당 라이선스가 허용하는 수정·재빌드·호환 DLL 교체·수정 사항 디버깅을 위한 역공학을 제한하지 않습니다.
수정한 라이브러리를 배포할 때에는 해당 라이선스의 수정 표시·상응 소스 등 조건도 따르세요.

## 언어 자료

eng·kor·osd는 tesseract-ocr/tessdata_fast의 고정 커밋 87416418657359cb625c412a48b6e1d6d41c29bd에서 내려받았습니다. 모델과실행.json에 SHA-256이 있습니다.
언어 자료의 Apache-2.0 원문은 vendor/tesseract/doc/tessdata_fast-LICENSE에 있습니다.
Windows 글꼴 파일은 동봉하지 않습니다. OCR용 tessdata/pdf.ttf는 공식 Tesseract 배포 자료이며 UI 시스템 글꼴과 별개입니다.
