1.11 파일 변환 — 세 단계로 시작하세요
1. 파일 선택을 누르거나 파일을 화면에 놓습니다.
2. 원하는 출력 형식을 고릅니다.
3. 변환을 누르고 결과를 확인합니다. 원본은 그대로 보존합니다.
저장한 작업과 전문 옵션은 필요할 때 펼쳐 사용하세요. PDF·OCR은 왼쪽 메뉴에서 열 수 있습니다.

작업 공간의 고급 기능
파일을 추가하고 카드 순서를 정한 뒤 작업 종류와 목표를 선택하여 레시피를 실행합니다.
Ctrl+K 명령 검색으로 OCR 교정·전후 비교·결과 검사·영역 가림·휠 설정을 찾을 수 있습니다.
품질·해상도 목표는 적용 옵션을 직접 켰을 때 사용합니다. 이름을 바꾼 복사본과 문서 OCR 출력에도 원본은 보존합니다.
새 작업 공간의 결과는 화면에 표시된 결과 폴더에 저장합니다. 기존 파일 변환 화면의 기본 저장 방식과 구분합니다.
교정한 OCR 텍스트는 TXT·PDF·DOCX·XLSX로 저장할 수 있습니다. 개인정보 검토 후보는 완전 탐지 보장이 아니며 확인한 영역만 새 파일에 가립니다.
크기 변경·워터마크·품질 및 용량 목표의 지원되는 GIF/WebP/APNG 처리는 프레임과 시간을 보존합니다. 지원하지 않는 다중 프레임 변환은 이유와 함께 거부합니다.
파일·폴더 선택창과 내부 검토 화면에는 같은 글꼴·흑백 표면·유한 모션을 사용합니다. 설정에서 모션을 줄일 수 있습니다.
자세한 구성과 제한은 1.9-확장안내.md와 빌드방법.md를 참고하세요.
이 차수 설치 폴더는 %LOCALAPPDATA%\Programs\FlipRing19이며 1.9의 설정·기록을 이어 사용합니다. 새 바로가기는 만들지 않습니다.

Windows 10/11 64비트에서 실행합니다. 고객 PC에는 Python이 필요하지 않습니다.
앱은 Windows 트레이에 상주하며, 트레이 아이콘을 두 번 클릭하면 작업 창이 열립니다.
작업 창은 어두운 사이드바와 밝은 본문으로 구성됩니다. 홈에서 파일을 선택하거나 놓아 변환하고, PDF·OCR·기록·설정으로 이동할 수 있습니다.
1.7에서는 파일별 작업 큐와 실패만 재시도, 이미지 원본·결과 미리보기, 기본·사용자 프리셋을 제공합니다.
출력 형식을 고른 뒤 실행하면 원본 폴더에 새 이름으로 저장합니다. 실행 전에 입력·도우미·쓰기·공간을 점검합니다.
예상 필요 공간은 보수적인 준비량이며 실제 결과 크기를 보장하지 않습니다.
PDF 페이지 편집은 실제 썸네일 드래그 순서 변경, 다중 선택 회전·삭제·추출, 확대와 새 파일 저장을 지원합니다.
1.8은 기본1160×820 논리 픽셀의 고정 창과 영역 구분·고배율 표시를 보완합니다. 사용 가능한 화면이 작으면 화면 안으로 맞추고 내용을 스크롤할 수 있습니다.
상세 사용 방법은 소스의 1.7-새기능안내.md와 1.8-화면안내.md를 확인하세요.
설정 안에서 한국어 또는 English를 선택할 수 있습니다.
언어는 화면에 즉시 적용되고 저장되어 다음 실행에도 유지됩니다.
모션 줄이기는 전용 설정 화면에서 선택하며 다음 실행에도 유지됩니다. 효과를 줄여도 조작과 작업 상태는 유지합니다.
파일명·파일 경로·변환 형식 이름은 원래 값으로 표시합니다.
흑백·회색의 화면과 선택 강조 모션을 사용합니다.
UI는 동봉된 SUIT Regular·Medium·SemiBold 글꼴을 사용합니다. 원문 SIL Open Font License 1.1과 출처는 licenses\SUIT에 있습니다. Windows 글꼴 파일은 재배포하지 않습니다.
화면 아이콘은 동봉된 Lucide 원본 SVG이며 ISC·Feather MIT 원문 고지와 고정 커밋·해시는 licenses\Lucide에 있습니다.
PDF 변환용 나눔고딕 Bold와 OFL은 동봉 자료에 유지합니다.

탐색기에서 파일을 드래그하기 시작한 뒤 Shift를 누르면 원형 메뉴가 나타납니다.
파일을 원 안으로 끌어오면 가능한 출력 형식이 표시됩니다.
원하는 형식 위에 파일을 놓으면 변환하며, 가운데 ×에 놓으면 취소합니다.
Shift를 누른 Windows 이동 제안 대신 앱은 복사 동작만 받습니다.
Esc는 원형 메뉴를 닫고 Windows 드래그를 취소하는 데 사용할 수 있습니다.
여러 파일은 모두가 지원하는 공통 형식만 표시합니다.

트레이의 파일 선택/폴더 선택에서도 원형 메뉴를 열 수 있습니다.
이 방식에서는 원하는 형식을 마우스 왼쪽 버튼으로 클릭하세요.
오른쪽 버튼은 변환을 시작하지 않습니다.
설정창의 파일 선택/폴더 선택도 같은 방식입니다.
설정창에 파일이나 폴더를 직접 놓아 원형 메뉴를 열 수도 있습니다.

원본은 보존하고 같은 폴더에 새 결과를 저장합니다.
같은 이름이 있으면 '이름 2.ext'처럼 새 이름을 사용합니다.
여러 페이지를 이미지로 변환하면 '이름 (png)' 등의 폴더를 만듭니다.
PDF에서 문서로 변환할 때는 텍스트만 추출하며 원래 배치와 OCR은 포함하지 않습니다.
기존 일반 변환 엔진의 GIF·여러 장 이미지 입력은 첫 프레임을 사용하는 경로가 있습니다. 새 작업 공간의 다중 프레임 지원 범위와 구분해 결과를 확인하세요.
탐색기 아이콘의 정확한 옆 좌표 배치는 제공하지 않으며 Windows 정렬을 따릅니다.
Fn은 Windows에서 전달되지 않을 수 있으므로 다른 키를 지정하세요.

오디오·비디오: FFmpeg 필요
EPUB·Markdown 및 일부 문서: Pandoc 필요
Office 문서·프레젠테이션·스프레드시트: LibreOffice 필요
RAR: 동봉된 7-Zip 해제 도구 사용
트레이 또는 설정의 도우미 도구에서 설치 명령을 복사할 수 있습니다.
FFmpeg·Pandoc·LibreOffice는 고객 배포물에 포함하지 않습니다. RAR용 7-Zip 실행부와 원문 고지·전체 상응 소스는 포함합니다.

등장·퇴장·선택 강조에는 부드러운 모션이 있습니다.
드롭 창 좌표와 크기를 고정하고 창 내부에서만 모션을 그립니다.
원형 메뉴가 닫힌 뒤 같은 드롭이 다시 전달되어도 변환을 반복하지 않습니다.

설정·기록은 %LOCALAPPDATA%\PUVKID\DragWheel에 저장합니다.
자동 시작은 직접 선택할 때만 해당 Windows 계정에 등록합니다.
창 닫기는 트레이로 숨깁니다. 종료는 트레이 메뉴를 사용하세요.
변환 중에는 작업이 끝난 뒤 종료할 수 있습니다.
다른 위치에 있는 드래그 휠과 동시에 실행하지 마세요. 실행 잠금 파일을 공유합니다.
인증·TPM·체험·에디션·만료·사용 횟수·통신 인증 제한은 없습니다.

프로그램 폴더 전체를 보존해 주세요. EXE만 옮기면 실행되지 않습니다.
배포 시 FlipRing-Setup.exe 또는 프로그램 폴더 전체를 사용하세요.
프로그램 경로: 프로그램\FlipRing\FlipRing.exe
기본 설치 경로: %LOCALAPPDATA%\Programs\FlipRing19
기존 DragWheel의 설치 폴더와 분리됩니다. 설치 프로그램에서는 한국어·영어를 선택할 수 있습니다.
PySide6/Qt는 LGPLv3 조건으로 동적 로드합니다.
_internal의 호환 Qt/PySide 라이브러리를 교체할 수 있습니다.
해당 라이브러리 수정의 디버깅을 위한 역공학을 제한하지 않습니다.
구성요소의 저작권 고지와 라이선스는 동봉 licenses 폴더에서 확인하세요.
Qt/PySide 소스: https://download.qt.io/official_releases/QtForPython/pyside6/
Qt 소스: https://download.qt.io/official_releases/qt/
앱 전체 소스·번역·빌드·검사 코드·필수 자산·원 상응 소스는 같은 고객 폴더의 플립링-1.11.0-전체소스.zip으로 제공합니다.

검증 범위와 실제 탐색기 시험 여부는 별도 검증 보고서를 확인해 주세요.
Qt 이벤트 모형 시험 통과는 실제 탐색기 Shift 드래그 검증을 대신하지 않습니다.

PDF·OCR
PDF 도구에서는 합치기·분할·페이지 추출/삭제/회전·이미지와 PDF 변환·압축을 사용할 수 있습니다.
OCR은 한글·영문 인식, TXT·검색 가능한 PDF·Word·Excel 결과를 로컬에서 생성합니다.
OCR 엔진과 언어 모델은 동봉되어 별도 OCR 설치가 필요하지 않습니다.
처리 중 진행 상태를 확인하거나 취소할 수 있으며 원본 파일은 보존합니다.
인식 정확도는 원본 품질에 따라 달라집니다. 글자·숫자·문장·표를 결과와 대조해 주세요.
Word 배치와 표·셀 구조는 추론하므로 원본의 복잡한 배치·수식·병합 셀을 완벽하게 복원하지 못합니다.
PDF 압축은 문서에 따라 용량이 줄지 않을 수 있습니다.
변환 기록 항목을 마우스 왼쪽 버튼으로 두 번 클릭하면 결과 파일을 탐색기에서 선택합니다.
OCR 구성요소의 라이선스와 상응 소스는 licenses\OCR에 있습니다.

1.10 대표 문서 지원
HWP/HWPX, 구형 DOC·PPT·XLS, 최신 Word·PowerPoint·Excel, 템플릿·매크로 문서와 OpenDocument 등의 입력을 확장했습니다.
지원 입력과 저장 형식은 도구 화면에 각각 표시됩니다. 모든 형식을 서로 변환하거나 모든 서식을 완벽히 보존한다는 의미는 아닙니다.
구엑셀 XLS의 읽기와 저장을 지원하며 XLSB는 입력 전용입니다. CSV/TSV는 첫 시트의 표시값만 저장합니다.
DOCX/TXT/HWP5/HWPX에서 HWP/HWPX로 제한 저장합니다. 이 경로는 한컴·계정·업로드 없이 앱에서 실행합니다. 일반 Office 변환과 HWP→PDF/Word/이미지 등 기존 읽기에는 LibreOffice가 필요하며 H2Orestart·Java는 동봉합니다. 새 저장은 기본 문자·굵기·기울임·직사각형 표·내부 PNG/JPEG를 옮기며, 병합·중첩표·수식·외부 관계·보호 문서 등 미지원 구조는 거부합니다. HWP5 출력은 실험적이며 글꼴·전체 배치의 동일성과 모든 문서의 호환을 보장하지 않습니다. 구조 검사는 수행하지만 한컴 시각 검사는 실행하지 않습니다.
Word·PowerPoint·Excel의 고급 서식·차트·외부 데이터·매크로 등의 결과는 직접 확인하세요.
문서는 원본을 보존하고 새 이름으로 저장합니다. Office 문서의 매크로와 외부 링크 갱신을 실행하지 않는 옵션으로 격리된 변환 프로세스에서 엽니다.
자세한 범위와 제한, 전체 빌드 방법은 소스/1.10-문서지원안내.md와 소스/빌드방법.md에 있습니다.

1.11 전체 소스와 재배포
실행 프로그램은 프로그램\FlipRing 폴더 전체, 설치 프로그램은 설치파일\FlipRing-Setup.exe를 사용합니다.
전체 소스 ZIP과 고지·빌드방법을 고객 폴더에 함께 보존해 주세요. licenses\전체소스_안내.txt에 정확 소스 파일명·SHA-256·Release와 자산 URL을 기록합니다.
정확히 확인한 큰 상응 소스 archive 10개만 실행 폴더의 중복 보관에서 분리하며 전체 소스 ZIP에는 원바이트로 보존합니다.
원 고지·저작권·출하목록·패치·빌드 recipe는 유지합니다. licenses의 목록에 기록된 archive는 전체 소스 ZIP에서 찾을 수 있습니다.
온라인 재배포 시에는 같은 장소에서 무료로 동등한 상응 소스 접근을 제공할 수 있습니다. 원 개발자 URL만 남겨 재배포자의 소스 제공 의무가 자동 면제되는 것은 아닙니다.
호환 Qt/PySide 동적 라이브러리를 교체할 수 있으며 수정 디버깅을 위한 역공학을 제한하지 않습니다.
예정 공개 Release: https://github.com/PUVKID/FlipRing-File-Converter-Project/releases/tag/v1.11.0
실제 게시와 로그인 없는 파일 접근은 별도 확인이 필요하며 예정 주소만으로 게시 완료를 의미하지 않습니다.
