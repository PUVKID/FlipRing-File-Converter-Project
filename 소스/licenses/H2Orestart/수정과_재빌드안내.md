# H2Orestart 전체 그림 경계 수정과 재빌드

수정일: 2026-11-25. 기준은 **H2Orestart v0.8.0**, 로컬 수정 표시는 **flipring-fullbounds1**입니다. 원본 GPL 고지·COPYING과 공식 원본 압축을 보존합니다.

64×48 PNG를 포함한 원본 문서의 전체 그림 범위 9071×6803이 폭 비율에 따라 47.99823760986328픽셀 높이로 계산되고 정수 47로 잘리는 문제를 수정했습니다. **원본 전체 사각형인 경우에만 픽셀 자르기를 생략**합니다. 실제 부분 자르기의 기존 계산과 처리 경로는 유지합니다.

컴파일에는 Eclipse Temurin JDK **17.0.21+9**와 공식 LibreOffice 설치의 `program/classes/libreoffice.jar`를 사용했습니다. `--release 8`로 원본과 같은 클래스 major 52를 유지합니다. 새 JDK나 UNO JAR을 제품에 추가로 동봉하지 않습니다. 원본 JAR의 `ConvGraphics.class`와 `$1.class`를 교체하고 같은 단일 소스를 컴파일한 enum-switch 보조 `$2.class`만 추가합니다. 그 밖의 JAR 항목과 OXT의 JAR 외 항목은 비압축 바이트가 모두 같습니다.

아래 경로 인자는 각 환경의 실제 위치로 지정합니다. `--output`은 기존 파일이 없는 새 경로여야 합니다.

```powershell
python -B -X utf8 재빌드.py --jdk-home "JDK17 경로" --libreoffice-home "LibreOffice 경로" --upstream-oxt H2Orestart-v0.8.0-original.oxt --output "새 H2Orestart.oxt"
```

실제 출하 OXT는 **606,897바이트**, SHA-256 `6a12a08a4c10bd4e020c4bce9dc9315046a71bf5dc3061ad9405e456d75a13ab`입니다. 정확한 공식 원본 OXT와 소스 압축 해시는 원본출처.json의 upstream_binary/source에 보존합니다. 공식 원본 URL을 수정 바이너리의 다운로드 주소로 표시하지 않습니다.

## 고정 표본과 실제 확인

표본 문서는 이 묶음에 포함하지 않습니다. 원본을 확보한 경우 다음 고정 SHA-256과 대조합니다.

| 필요한 원본 | SHA-256 |
|---|---|
| 자체도형.png | 21a28dbff764e06d46cb712f91b6bc0dd9e7521bd0e5c4883ebeddd72f3b1d09 |
| 자체기능.hwp | 07aa09c7a256e7da4df30b5ffbb6ca78cab02a1b6bde33dcaa3d219195a16e75 |
| 자체기능.hwpx | 58b0ca9ef16e25de7b0b3ada0218ffd638fbd773cc586edd4ff67b6daeaa8e31 |

회귀 도구의 `--image`에는 자체도형.png, `--hwp`와 `--hwpx`에는 수정하지 않은 두 문서, `--expected-image-sha256`에는 위 PNG의 고정 값을 전달합니다. `--source-dir`에는 제품 engine.py가 있는 소스 폴더, `--oxt`에는 검사할 OXT, `--output`에는 아직 없는 결과 폴더를 전달합니다. `--help`에서 전체 인자를 확인할 수 있습니다. `--check-report`는 이미 생성된 네 결과의 파일·해시·픽셀만 읽으며 새 변환을 실행하지 않습니다.

**LibreOffice/H2Orestart 실제 재열기 4개가 통과**했습니다. HWP·HWPX 전체 그림 두 경로는 64×48 전체 RGB와 마지막 행이 원본과 같습니다. 부분 자르기 두 경로는 원본 clip을 left=2268, top=1701, right=6804, bottom=5103으로 설정한 제어 표본이며, 출력 32×24 전체 RGB와 마지막 행이 원본 픽셀 영역 (16,12)~(48,36)과 같습니다. 원본 파일 해시도 유지됐습니다. 35.563초, 실패·오류·건너뜀은 0개입니다.

기존 100×60 표본의 전체 RGB 보존 결과는 재사용했고 다시 변환하지 않았습니다. 이 검사는 그림 경계 수정의 근거이며 모든 문서의 서식·배치 또는 모든 뷰어의 일치를 보장하는 검사는 아닙니다. 실행 원문·로컬 경로·운영 실패 기록은 배포에 넣지 않습니다.
