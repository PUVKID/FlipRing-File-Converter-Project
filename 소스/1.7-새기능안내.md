# 플립링 1.7 작업 흐름

제작: PUVKID. 무료 배포판입니다. 실행 프로그램, 설치 파일, 전체 소스, 빌드 방법과 라이선스 자료를 프로젝트 폴더 하나에 보관합니다.

## 파일 변환

파일 변환 화면에서 파일을 선택하거나 놓습니다. 파일마다 대기·처리·완료·실패·취소 상태가 표시됩니다. 출력 형식을 확인한 뒤 실행하면 원본 폴더에 새 이름으로 저장합니다. 실행 전 입력과 도우미 도구, 쓰기 가능 여부, 여유 공간을 확인합니다. 필요 공간은 보수적인 추정이며 실제 결과 용량을 보장하지 않습니다.

실패한 파일만 재시도할 수 있습니다. 취소해도 원본과 이미 완료된 다른 결과는 유지합니다. 파일을 선택하면 지원되는 이미지의 원본과 결과, 크기와 용량을 비교할 수 있습니다. 미리보기를 지원하지 않는 형식은 안내에 따라 탐색기에서 확인합니다.

기본 프리셋 또는 저장한 사용자 프리셋으로 형식과 옵션을 불러옵니다. 프리셋 적용 후 직접 실행해야 하며 과거 파일 경로를 자동으로 다시 처리하지 않습니다. 사용자 프리셋은 이름을 지정해 저장하거나 삭제할 수 있습니다.

## PDF·OCR

기존 합치기·분할·추출·삭제·회전·이미지 변환·압축·한영 OCR과 TXT·검색 PDF·Word·Excel 내보내기를 유지합니다. 페이지 편집에서는 PDF를 열어 실제 썸네일을 확인하고 드래그로 순서를 바꿉니다. 여러 페이지를 선택해 회전·삭제·추출하거나 선택 페이지를 크게 볼 수 있습니다.

편집 결과는 새 파일로 저장합니다. 원본을 덮어쓰지 않습니다. 모든 페이지 삭제, 손상·암호화된 PDF, 누락된 입력은 처리하지 않고 이유를 표시합니다. 저장을 마친 직후 취소를 눌러도 완성된 파일은 완료 결과로 남습니다.

OCR 정확도는 입력 품질과 언어에 따라 달라집니다. 복잡한 표·수식·다단 문서의 배치를 완벽하게 복원하는 기능은 아닙니다. 압축 후 크기가 줄지 않을 수도 있습니다.

## 설정과 조작

기본 설정은 별도 설정 화면에 있습니다. 한국어·영어와 모션 줄이기를 선택할 수 있으며 재시작해도 유지됩니다. 모션 줄이기는 열린 내부 화면과 휠에도 적용하고 작업 자체는 유지합니다.

탐색기에서 파일을 드래그하며 기본 Shift 키를 누르면 원형 메뉴를 사용합니다. 원하는 형식에 놓아 변환하고 중앙에 놓아 취소합니다. 기록의 결과 항목을 왼쪽 마우스로 두 번 클릭하면 탐색기에서 해당 파일을 선택하며 파일을 실행하지 않습니다.

오디오·영상에는 FFmpeg, 일부 문서·전자책에는 Pandoc, Office에는 LibreOffice가 별도로 필요합니다. RAR용 7-Zip 해제 도구와 OCR 엔진·한영 모델은 동봉합니다. 7-Zip의 원문 고지와 동일 버전 전체 상응 소스는 `licenses/7Zip`에 있습니다.

## 추가 검사 재현

다음은 `소스` 폴더에서 실행합니다. 앞의 빌드 방법에 따라 Python 3.12 환경과 고정 의존성을 먼저 설치합니다. 출력 폴더는 새 폴더를 사용합니다.

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
.\.venv\Scripts\python.exe -B -X utf8 test_workbench.py
.\.venv\Scripts\python.exe -B -X utf8 test_pdf_workspace.py ..\work\pdf-workspace-check
.\.venv\Scripts\python.exe -B -X utf8 test_pdf_tools.py ..\work\pdf-tools-check --ocr --gui
Remove-Item Env:QT_QPA_PLATFORM
.\.venv\Scripts\python.exe -B -X utf8 test_conversion_matrix.py --root ..\work\conversion-matrix-check --timeout 35 --total-timeout 1200
```

변환 조합 검사는 외부 도우미와 각 입력 형식의 시험 자료를 사용합니다. 성공·실패·도우미 부재·입력 자료 부재를 구분한 보고서를 확인해야 합니다. 검사 통과와 실제 Windows 탐색기에서의 Shift/OLE 입력 확인은 별개입니다. 오프스크린 Qt 검사를 실제 화면 조작으로 표현하지 않습니다.

RAR 입력은 사용 권한을 확인한 별도 RAR 파일을 `--rar-fixture 파일경로`로 지정합니다. 지정하지 않으면 해당 입력은 시험 자료 부재로 기록하며 통과로 취급하지 않습니다. 이번 개발에서 사용한 자료는 ISC 고지가 있는 `markokr/rarfile` 저장소의 `test/files/unicode.rar`이며 자료·출처·해시는 개발 검증 폴더에 보존합니다. 고객 프로그램에는 이 외부 시험 파일을 포함하지 않습니다.
