## 미리보기 범위
파일 하나씩, 128MiB 이하를 미리 봅니다. 폴더는 미리보기 대상에서 제외됩니다. 실제 변환과 같은 도구가 필요하며, 없는 도구는 해당 설치 동작으로 연결합니다. 60초가 지나면 취소를 요청하고 변환기가 종료된 뒤 임시 파일을 정리합니다. 닫기/취소 중에는 스레드가 끝날 때까지 자원을 유지합니다.

이미지·PDF는 가능한 실제 그림/페이지를 표시합니다. Office·오디오·비디오·압축 등 시각 렌더러가 없는 출력은 생성된 파일 정보와 실제 크기를 표시합니다. 여러 이미지 결과는 첫 그림과 전체 결과 크기를 표시합니다. 원본이 미리보기 도중 바뀌면 결과를 사용하지 않고 다시 선택하도록 안내합니다.

미리보기는 저장된 최종 결과가 아니며 창을 닫으면 임시 결과를 지웁니다. 실제 변환은 ‘변환 실행’으로 진행합니다. 저장 공간 준비 예상과 실제 최종 용량은 구분합니다. 복잡한 문서의 서식·글꼴·쪽 배치, OCR 정확도와 모든 뷰어의 표시 동등성은 보장하지 않습니다. HWP 5 저장은 실험적 기능입니다. 움직이는 이미지의 프레임, 투명도, 텍스트·표·미디어의 정보 손실 가능성은 형식별로 안내합니다.

## English
Choose files, select the output format, then run conversion. Preview result converts a temporary copy with the same engine and reports the actual output size. Images and PDFs show supported visual previews; other outputs show generated-file information. Preview supports one file up to 128MiB, excludes folders, and requests cancellation after 60 seconds. Temporary files remain owned until the worker finishes, then are removed on close. A changed source invalidates the preview. Originals and existing outputs remain unchanged.

The main navigation contains Convert, PDF/OCR, History and Settings. More tools keeps the existing quick actions, workspace, helpers and app information accessible. Failures offer a relevant next action; technical details are collapsed. Light, dark, system theme, Korean/English and reduced motion remain available. Shift-drag in Explorer retains the original radial workflow; selecting files inside the app stays in the main work list.
