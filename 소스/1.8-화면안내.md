# 플립링 1.8 화면 안내

기본 창은 1160×820 논리 픽셀의 고정 크기입니다. Windows 배율에 따라 실제 픽셀 수가 달라집니다. 사용 가능한 화면이 작으면 그 영역 안으로 고정 크기를 맞추고 필요한 내용은 스크롤로 확인합니다.

메뉴의 현재 위치와 본문 경계, 프리셋·작업 목록·실행·원본과 결과 비교의 구분을 보강합니다. 흑백·회색과 SUIT 글꼴을 사용합니다. 한국어와 영어는 설정에서 선택합니다.

창 맞춤과 스크롤은 `fixed_viewport.py`, 이미지 고배율 처리는 `preview_panel.py`와 `pdf_panel.py`가 담당합니다. 이 모듈들을 전체 소스와 함께 복사해야 하며 PyInstaller가 자동으로 포함합니다. `test_fixed_layout.py`는 이 릴리스의 화면 크기·배율 검사를 담당합니다. 기존 변환 엔진과 설정 데이터 형식은 유지합니다.

개발용 Qt 오프스크린 렌더 검사는 실제 Windows의 디스플레이 배율 변경이나 탐색기 Shift 드래그 검사와 구분합니다. 세부 검증 결과는 프로젝트의 릴리스 기록에 보관합니다.

다음 명령은 `소스` 폴더에서 실행합니다. 동봉한 `offscreen-monitor.json`은 실제 모니터 설정을 바꾸지 않고 Qt 가상 화면 크기만 지정합니다.

```powershell
$env:QT_QPA_PLATFORM = "offscreen:configfile=offscreen-monitor.json"
$env:QT_SCALE_FACTOR = "1.5"
.\.venv\Scripts\python.exe -B -X utf8 test_fixed_layout.py ..\work\fixed-layout-150
Remove-Item Env:QT_SCALE_FACTOR
Remove-Item Env:QT_QPA_PLATFORM
```
