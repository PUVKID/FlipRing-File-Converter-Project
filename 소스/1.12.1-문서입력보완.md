# 플립링 1.12.1 문서 입력 보완

| 변경 | 동작 | 확인 범위 |
|---|---|---|
| **AbiWord 읽기** | 정확히 허용한 공식 DTD 선언만 격리 사본에서 제거 | 실제 ABW→DOCX, UTF-8·UTF-16, 다른 DTD·엔터티 거부 |
| **DIF 읽기** | 원본을 유지하고 UTF-8로 정규화한 사본을 읽기 | 실제 UTF-8·CP949 한글 셀, BOM UTF-16 단위 검사 |
| 프리셋 화면 | 펼친 영역이 내용 높이만 사용 | 한글·영문에서 제목과 입력 사이 간격 확인 |
| 문서 템플릿 검사 | 원본 XML 표기를 보존하는 합성 입력 생성 | DOT·POT·PPS·XLT·DOTM·POTX·POTM·PPSM·XLTM·SXW·STW·SLK |

DIF 문자집합은 기존 텍스트 입력과 같은 순서로 읽습니다. BOM UTF-16을 우선하고, 그 밖에는 UTF-8·CP949·Windows-1252를 순차 적용합니다. 인코딩 정보가 없는 모든 문자의 뜻을 자동 판별하는 보장은 아닙니다. 사본 이름이 충돌하면 기존 파일을 덮어쓰지 않습니다.

구형·신형 Pages/Numbers의 실제 본문과 대표 셀을 대조했습니다. 새 HWP·HWPX는 별도 LibreOffice/H2Orestart로 다시 열어 한글·표·그림을 확인했습니다. HWP5 저장의 기존 실험적 범위, 복잡한 배치·개체의 호환성 제한은 유지합니다. 모든 한컴 버전의 동일 시각 배치를 확인했다는 의미가 아닙니다.

기존 오류·취소·원본 보존 검사의 유효한 결과는 재사용합니다. 소스 검사, Windows 설치·기동, 탐색기 Shift 드래그와 외부 도구의 실제 설치 성공은 서로 다른 확인 항목입니다. 실행하지 않은 항목을 통과로 간주하지 않으며, 모든 미래 입력과 환경의 절대 무결함을 보장하지 않습니다.

전체 소스 ZIP에는 제품 소스, 빌드 방법, 검사 코드, 필요한 라이선스와 상응 소스를 포함합니다. 타 저장소의 시험용 문서 표본과 비공개 운영 기록은 배포에 넣지 않습니다.
