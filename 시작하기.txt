플립링 (FlipRing) — 제작 PUVKID

실행: 프로그램\FlipRing\FlipRing.exe
설치: 설치파일\FlipRing-Setup.exe
전체 소스·검사·고정 의존성: 소스
빌드 방법: 소스\빌드방법.md
라이선스·관련 라이브러리 소스: 소스\licenses
검증 자료와 역할 기록: evidence

1.7 작업 창은 어두운 사이드바와 밝은 본문으로 구성됩니다. 파일 변환 화면에서 파일을 선택하거나 놓고 출력 형식을 고른 뒤 실행합니다. PDF·OCR·기록·설정은 별도 화면으로 이동합니다.
파일별 작업 상태와 실패만 재시도, 원본·결과 미리보기, 기본·사용자 프리셋을 제공합니다.
새 기능과 검사 재현: 소스\1.7-새기능안내.md

설정의 Language / 언어에서 한국어 또는 English를 선택합니다.
선택은 즉시 적용되며 다시 실행해도 유지됩니다.
같은 설정 화면의 모션 줄이기도 저장되어 열린 내부 화면과 원형 메뉴에 적용됩니다.
탐색기에서 파일을 끌면서 기본 Shift 키를 누르고 원하는 형식 위에 놓습니다.
원형 메뉴 중앙에 놓으면 취소합니다. 원본 파일은 보존합니다.
기록의 결과 항목을 왼쪽 마우스로 두 번 클릭하면 탐색기에서 파일을 선택합니다.
기록 동작으로 파일 자체를 실행하지 않습니다.

PDF·OCR 탭에는 다음 기능이 있습니다.
- PDF 합치기·분할·페이지 추출·삭제·회전
- 여러 이미지와 PDF 간 변환, 무손실 정리·이미지 압축
- 한글·영문 이미지와 스캔 PDF의 문자 인식
- 검색 가능한 PDF·TXT·Word 문서·Excel 셀 내보내기
- 작업 진행과 취소, 결과 기록
- 실제 페이지 썸네일과 확대, 드래그 순서 변경, 다중 선택 회전·삭제·추출과 새 PDF 저장

파일 목록의 순서는 위에서 아래입니다. 필요한 페이지 범위와 작업 옵션을 선택하세요.
압축 옵션과 문서·표 인식의 안내를 확인하세요. OCR 정확도는 스캔 품질에 따라 달라집니다.
복잡한 표·병합 셀·다단 문서의 원래 배치를 완벽하게 재현하는 기능은 아닙니다.
암호화된 PDF는 지원하지 않습니다. 원본을 보존하고 새 이름으로 결과를 저장합니다.

무료 배포판이며 인증키·체험판·만료·횟수 제한이 없습니다.
OCR 엔진과 한국어·영어 모델은 동봉되어 별도 관리자 설치가 필요하지 않습니다.
오디오·영상·일부 Office/전자책 변환은 도구 탭에서 외부 도우미 설치 상태를 확인하세요.
설치한 앱과 프로그램 폴더의 앱을 동시에 실행하지 마세요. 설정과 기록은 같은 Windows 계정에서 공유됩니다.
UI용 SUIT Regular·Medium·SemiBold TTF 3개와 SIL Open Font License 1.1 원문·출처를 동봉합니다. 자료는 소스\assets\fonts와 소스\licenses\SUIT에 있습니다.
Lucide 원본 SVG 12개와 ISC·Feather MIT 고지·고정 커밋·해시도 소스\assets\lucide와 소스\licenses\Lucide에 동봉합니다.
Windows 시스템 글꼴은 재배포하지 않습니다. PDF 변환용 나눔고딕과 OFL은 UI용 SUIT와 별도로 유지합니다.
코드 서명 인증서는 포함하지 않습니다.

1.6에서는 파일·폴더 선택창과 내부 메시지·메뉴·목록·입력·작업 상태를 공통 흑백 디자인과 유한 모션으로 연결했습니다.
실제 확인한 검증 범위와 제한은 evidence 폴더의 최신 검증 기록을 확인하세요.
