# 플립링 1.12 빠른 작업

**빠른 작업**에서 파일이나 폴더를 추가하고 작업을 선택한 뒤 실행합니다. 세부 설정은 고급 옵션에서 펼칩니다.

| 영역 | 사용 방법 |
|---|---|
| 테마 | 상단에서 라이트·다크·시스템 중 선택합니다. 선택은 다음 실행에도 유지합니다. |
| 빠른 작업 | 자주 사용하는 출력 형식·품질·크기·목표 용량을 저장합니다. |
| 폴더 | 하위 폴더 구조를 유지하고 확장자로 대상을 고를 수 있습니다. |
| 대기열 | 작업 추가·순서 변경·일시 정지·계속·취소·실패 재시도를 제공합니다. |
| 미리보기 | 이미지 전후·투명 배경·파일 크기를 확인합니다. 문서는 기존 미리보기로 연결합니다. |
| 결과 관리 | 결과 위치를 열고 파일을 선택하거나 경로를 복사합니다. 정리는 앱이 만든 변경 없는 결과만 대상으로 합니다. |
| 외부 도구 | 외부 도우미 화면의 설치 버튼으로 공식 패키지 설치를 진행합니다. Windows 권한 확인이 나타날 수 있습니다. |

원본은 보존합니다. 목표 용량을 달성하지 못하면 달성했다고 표시하지 않습니다. 설치에 인터넷·Windows 패키지 관리자와 도구별 설치 권한이 필요합니다. HWP 출력의 복잡한 서식 제한과 LibreOffice 등 별도 프로그램의 필요 조건은 기존과 같습니다.

전체 소스 ZIP에는 제품 코드·검사 코드·정확한 포함 라이브러리 소스·라이선스·빌드 방법이 포함됩니다. 실행 시 프로그램 폴더 전체를 유지하세요.
