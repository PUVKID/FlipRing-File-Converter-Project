# 플립링 1.13.0 변경 기록

**상태: 제작 중.** 실행 파일·설치 파일과 실제 탐색기 동작 확인, 공개 반영이 아직 끝나지 않았습니다.

| 변경 | 구현 내용 | 현재 근거와 남은 확인 |
|---|---|---|
| 작업 대기열 | 재시작 후 명시적 이어하기, 입력·완료 결과의 해시 확인 | 새 코어·화면 검사 근거 확보, 최종 묶음 확인 예정 |
| 결과 정리 | 작업 묶음 보관·충돌 보호·정리 되돌리기 | 재시작·변경 파일 보호 확인 |
| 목적별 작업 | 메일·인쇄·웹 기본값 | 목표 용량은 달성 여부를 구분 |
| 결과 이름 | PDF 다중 페이지와 문서 실제 출력 수 미리보기 | 연결 대기25→60초 보완, 실제2페이지 예정·출력 이름 일치 확인. 미리보기와 변환 시험71.554초, 실행본 확인 별도 |
| 개인정보 | PDF·OOXML·JPEG·PNG 선택 메타데이터를 새 사본에서 제거 | JPEG 패딩·전체 메타데이터 잔류 방어 수리, 지원 범위 별도 안내 |
| 비교와 OCR | 문서 전후 비교, 다중 프레임 이미지, 인식 위치·읽기 순서 | 자동 누락 검출이나 서식 완전 보존을 보장하지 않음 |
| 공유 진단 | 허용된 버전·상태·형식·오류 분류만 저장 | 파일명·경로·본문·원문 오류 제외 |
| 사용 화면 | 도구별 구획, 차분한 상태 피드백 | 라이트·다크·언어·페이지 조작 소스 검사 통과. 설치본 화면 확인 별도 |
