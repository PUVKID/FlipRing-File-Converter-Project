# 플립링 1.12.0 설계와 기능 검토

목적은 기존 원형 메뉴·문서 변환을 유지하면서 반복 작업을 쉽게 만드는 것입니다. 기존 PySide6·workspace_core를 확장합니다. 화면을 완전히 새로 만드는 방식은 기능 중복과 배포 크기를 늘려 제외했습니다. 기존 동작을 유지하며 빠른 작업 중심으로 확장합니다.

## 필수 변경

- 라이트·다크·시스템 테마를 저장하며 파일 선택창·팝업·PDF·OCR·미리보기까지 적용합니다.
- 공식 패키지 ID로 도구를 비동기 설치하고 진행·실패·재탐지를 표시합니다. 사용자 동작에 따른 설치이며 UAC나 실제 라이선스 확인을 우회하지 않습니다.
- 기존 7가지 제안 모두 반영: 빠른 작업, 전후 비교, 폴더 변환, 목표 용량, 대기열, 결과 정리·되돌리기, 변환 가능 여부.
- 50가지 기능·개선 항목을 아래에 정리했습니다. 기존 기능은 재사용하고 새로 바뀐 지점만 확인합니다.

## 수락 조건

원본은 보존하고 결과만 새로 만듭니다. 폴더 연결을 따라가지 않습니다. 되돌리기는 이 앱이 만든 결과 중 해시가 변하지 않은 파일만 대상으로 합니다. 설치는 셸 문자열 없이 허용 패키지 ID로 실행합니다. 기존 정상 배포는 새 배포 확인 전 유지합니다.
