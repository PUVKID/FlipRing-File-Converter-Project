# 플립링 1.13.0 사용 안내

빠른 작업에서 파일이나 폴더를 추가하고 결과 폴더와 작업을 선택합니다. **원본은 보존하며 결과는 새 이름으로 저장합니다.** 이 안내는 제작 중인 소스 기준이며, 진행 중인 기능과 제한을 함께 표시합니다.

| 기능과 구분 | 사용 순서 | 주의와 제한 |
|---|---|---|
| **1. 전후 비교** · 기존 비교 유지, 문서 비교 추가 | 결과를 선택해 원본과 결과를 보거나, `호환 안내 · 개인정보 · 문서 비교`의 `전후 비교` 탭에서 두 파일을 고르고 `문서 전후 비교`를 누릅니다. 페이지 번호를 바꿔 비교합니다. | 이미지·PDF 미리보기와 추출 텍스트 차이를 활용합니다. 문서 비교는 도우미가 필요할 수 있으며 화면과 텍스트의 일치가 모든 서식·내용의 완전한 보존을 뜻하지 않습니다. |
| **2. 파일별 호환 안내** · 신규 연결 | 같은 도구의 `호환 안내` 탭에서 파일과 출력 형식을 고르고 `호환 확인`을 누릅니다. 글꼴·수식·매크로 등 안내를 읽고 변환 여부를 결정합니다. | 제한된 내부 검사입니다. 흔적이 발견되지 않아도 내용이나 배치가 보존된다는 보장은 없습니다. 보호 문서·복잡한 개체와 도우미 요구를 확인하세요. |
| **3. 실패 작업 재시도** · 기존 유지 | 대기열 처리 후 `실패 작업 재시도`를 누릅니다. 이미 완료한 입력은 제외하고 실패한 나머지를 다시 처리합니다. | ZIP 묶음 단계만 실패한 경우 해당 단계만 재시도할 수 있습니다. 원인과 결과를 확인하세요. |
| **4. 목표 용량** · 기존 유지 | 작업 설정의 `목표 KiB`에 원하는 크기를 입력하고 변환합니다. 0은 제한 없음입니다. 결과의 목표 달성 여부를 확인합니다. | 이미지·PDF 출력에서 지원합니다. 목표에 못 미쳐도 결과를 보존하며 미달성으로 표시합니다. |
| **5. 사용자 작업 저장** · 기존 유지 | 형식·품질·크기·이름 규칙 등을 정하고 `작업 저장`을 눌러 이름을 입력합니다. 이후 저장한 작업을 선택해 사용합니다. | 빠른 작업 설정을 저장하며 입력 파일과 결과 경로를 저장 작업에 포함하지 않습니다. |
| **6. 작업 묶음 정리와 되돌리기** · 작업 단위 확장 | 대기열에서 작업을 선택하고 `선택 작업 묶음 정리`를 누릅니다. 보관한 결과를 되돌리려면 `정리 되돌리기`를 누릅니다. | 영구 삭제가 아니라 앱이 만든 결과를 보관 위치로 옮깁니다. 해시가 바뀌었거나 복원 이름이 충돌하면 보호 안내를 확인하세요. |
| **7. 폴더 구조 유지** · 기존 유지 | `폴더 추가`로 입력하고 결과 폴더를 지정한 뒤 대기열에 넣습니다. 필요하면 확장자 필터를 설정합니다. | 선택 폴더 아래의 상대 구조를 결과에 반영합니다. 연결 파일·폴더는 따라가지 않으며 건너뛴 항목은 확인해야 합니다. |
| **8. 메일·인쇄·웹 용도** · 기본 작업 추가 | 빠른 작업 목록에서 용도를 고르고 필요에 따라 설정을 바꿔 저장합니다. | 메일용은 JPG 품질 80·너비 1600px·목표 1MiB, 인쇄용은 PDF 품질 95·크기 자동·목표 없음, 웹용은 WebP 품질 80·너비 1920px·목표 512KiB입니다. 목표는 달성을 보장하지 않습니다. |
| **9. 개인정보 선택 제거** · 신규 | `호환 안내 · 개인정보 · 문서 비교`의 `개인정보` 탭에서 파일을 고르고 `메타데이터 탐지`를 누릅니다. 제거할 항목을 선택하고 저장 폴더를 지정한 후 `선택 제거 사본 저장`을 누릅니다. | PDF·OOXML·JPEG·PNG의 지원되는 탐지 항목만 선택 제거합니다. 다른 형식은 선택 제거를 지원하지 않습니다. 원본은 그대로이며 본문·첨부·댓글 등은 별도 검토가 필요합니다. |
| **10. OCR 위치와 읽기 순서** · 기존 교정 확장 | OCR 교정에서 파일을 선택해 `문자 인식`을 실행하고 `인식 위치와 읽기 순서 보기`를 켭니다. 번호와 목록을 선택해 페이지의 실제 인식 위치를 확인하고 텍스트를 교정합니다. | 번호가 없는 원본 글자·표를 직접 대조하세요. 자동 누락 검출을 보장하지 않습니다. 기존 교정 텍스트를 보존합니다. |
| **11. 결과 이름 충돌 미리보기** · 확장 | 입력·작업·결과 폴더를 정하고 `이름 미리보기`에서 예정 이름을 확인합니다. | 기존 파일과 같은 묶음의 이름을 고려합니다. 실행 중 외부 변경이 있으면 실제 이름이 달라질 수 있습니다. PDF는 실제 페이지 수를 반영합니다. 문서는 명시적인 미리보기에서 안전한 임시 변환으로 결과 수를 확인합니다. Office 연결 대기를 보완한 소스에서 2페이지 문서의 예정 이름과 실제 결과 이름 일치, 원본 보존을 확인했습니다. 느린 최초 시작의 세부 원인은 미측정이며 새 배포본 확인은 별도입니다. |
| **12. 중단 후 이어하기** · 신규 | 다시 시작하면 복구된 대기열 상태를 확인하고 `계속`을 직접 누릅니다. 재확인 필요 항목은 입력과 결과를 살핀 뒤 안내에 따라 처리합니다. | 자동 실행하지 않습니다. 입력과 완료 결과의 SHA-256을 확인하며 변경·중단 경계는 재확인이 필요합니다. 오래되거나 손상된 기록은 보존하고 오류를 표시합니다. |
| **13. 공유 진단** · 신규 | `공유 진단 미리보기`를 눌러 표시 내용을 확인한 뒤 저장하거나 취소합니다. | 허용된 버전·상태·형식·오류 분류만 담습니다. 경로·파일명·문서 본문·원문 오류·실제 설정값은 제외합니다. 일반 `요약 저장`은 공유 진단과 별개입니다. |

라이트·다크·시스템 테마와 기존 문서 작업은 계속 사용할 수 있습니다. 변환이나 정리 전에는 대상과 저장 위치를 확인하고, 결과는 사용 목적에 맞게 직접 검토하세요.

내부 도구는 **호환 안내·개인정보·전후 비교** 탭으로 나뉩니다. 각 탭의 안내를 따라 현재 작업에 필요한 항목만 선택합니다. 입력 중 테두리 강조는 반복하지 않으며, 진행률과 선택 피드백은 간격을 두고 표시합니다. 움직임 축소를 켜도 최종 상태와 작업 결과는 그대로 반영합니다.
