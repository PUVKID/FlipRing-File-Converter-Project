새 **작업 공간**에서 파일을 모아 목표 형식·용량·페이지 규격을 지정하고, 검토한 처리 순서를 레시피로 저장하는 버전입니다.

Ctrl+K 명령창, 원본을 보존한 이름 규칙 복사, 파일 카드 조합, 결과 비교, 기록 검색·필터·복사, 감시 폴더, 휠 개인화, 클립보드 입력과 직접 시작한 영역 캡처를 추가합니다. PDF·OCR 검토에서는 실제 인식 신뢰도와 위치를 확인하고 텍스트를 수정하여 TXT·PDF·DOCX·XLSX로 저장합니다.

개인정보 후보는 검토 보조입니다. 사용자가 확인한 영역만 새로운 결과 파일에 가립니다. 자동 탐지가 모든 개인정보를 발견한다는 보장은 없습니다. 압축 목표를 달성하지 못한 경우 달성한 것으로 표시하지 않습니다. 원본을 덮어쓰지 않습니다.

모션은 선택·처리·완료 등 실제 작업 상태를 따라 움직이는 코드 기반 파일 카드와 화면 전환입니다. 설정의 모션 축소를 사용할 수 있습니다. PDF·OCR 정확도와 지원 입력은 실제 문서 구성에 따라 달라집니다.

## 보관 구성

- `프로그램/FlipRing/FlipRing.exe`: 실행 프로그램과 필요한 동적 라이브러리
- `설치파일/FlipRing-Setup.exe`: Windows 10/11 x64 설치 파일
- `소스`: 전체 소스, 고정 의존성, 검사 코드, 빌드 방법, 글꼴과 라이선스·상응 소스
- `SHA256SUMS.txt`: 배포 파일별 SHA-256

이 문서는 구현 범위를 설명합니다. 빌드·실행·검증 완료 여부와 남은 제한 사항은 차수 상위의 검증 결과 문서로 확인합니다. 실제 탐색기 Shift 드래그 확인과 오프스크린 자동 검사는 구분합니다.

제작: PUVKID. 무료 배포. 포함된 라이브러리의 원문 고지와 라이선스를 보존합니다.
