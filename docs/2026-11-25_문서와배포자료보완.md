# 1.12.1 공개 안내·배포 자료 보완

제품 28개 파일의 직전 차수 비교와 별개로 **공개 문서의 읽기 방식과 원본 고지 보존**을 정리했습니다. 앱 기능 추가나 재빌드로 집계하지 않습니다.

| 구분 | 실제 변경 | 보존·확인 범위 |
|---|---|---|
| 다섯 읽기 수준 | LEVEL 1~5의 주요 본문 구획에 표 23개 추가 | 기존 설명·수치·실패·앵커·링크 유지 |

| 분할 본문 네 파일 | 1.7·1.9의 결과·제약 구획에 표 10개 | 상단 요약표로 본문을 대체하지 않음 |
| 공개 원본 사본 48개 | 후속 공백 정비로 달라진 고정 파일·라이브러리 이름을 원본 바이트로 복구 | 제품 코드·로컬 원본·기존 검토와 같은 별도 정제본 12개는 유지 |
| 표 행 표시 | 일반 문서 세 파일의 표 행 사이 빈 줄 65개 제거 | 문장·수치·전체 비교 원문은 유지 |
| 현재 배포 안내 | 실행·설치·전체 소스의 크기·해시와 실제 확인·미확인을 구분 | 전체 기능 완료 판정 보류, 검증 후보 상태 |
