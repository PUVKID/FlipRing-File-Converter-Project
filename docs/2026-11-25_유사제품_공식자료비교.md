## 플립링과 비교할 지점

아래 플립링 항목은 1.13.0 제작 중 소스와 [13가지 기능 안내](2026-11-25_13가지기능_사용안내.md)의 정적 대조입니다. 완료된 제품의 실행 검증 결과가 아닙니다. Office 문서 미리보기는 연결 대기를 보완한 소스에서 **2페이지 예정 이름과 실제 결과의 일치·원본 보존을 확인**했습니다. 미리보기와 변환 시험은71.554초였으며, 느린 최초 시작의 세부 원인과 새 배포본의 확인은 구분합니다.

| 비교 영역 | 현재 중복·빈틈과 판단 |
|---|---|
| 끌어 놓기·진입 | 원형 메뉴와 빠른 작업을 재사용합니다. 입력→형식→실행의 실제 조작 횟수와 동작은 직접 확인 전이며 타 제품보다 빠르다고 단정하지 않습니다. |
| 형식·의존성 | 기존 파일별 지원 및 도구 상태가 있습니다. 입력·출력 방향, 도구 필요 여부와 제한을 선택 시 한곳에 보여 주는 연결이 중요합니다. 형식 수만으로 무손실·양방향을 주장하지 않습니다. |
| 일괄·복구 | 실패 재시도·목표 용량·폴더 구조·저장 작업은 기존 기능입니다. 작업 묶음 보관·복원과 재시작 후 명시적 이어하기는 제작 중 연결을 확인해야 합니다. |
| 미리보기·이름 | 기존 이미지·PDF 비교와 충돌 회피를 사용합니다. 문서 전후 비교, PDF 다중 페이지·문서의 실제 결과 수를 반영한 예정 이름은 현재 완성으로 취급하지 않습니다. |
| 개인정보 | 지원 형식에서 선택 메타데이터를 새 사본에 제거하고 공유 진단은 허용된 항목만 담는 방향입니다. 본문·첨부·댓글의 개인정보까지 제거했다고 주장하지 않습니다. |
| 화면과 동작 | 기본 작업, 진행·오류·결과를 먼저 보여 주고 호환·개인정보 등은 필요할 때 펼칩니다. 라이트·다크와 움직임 축소를 유지하고 실제 화면에서 확인해야 합니다. |

## 우선순위 제안

| 순서 | 구체적인 개선·성공 조건 |
|---|---|
| 1 | **문서 미리보기 완성**: 실제 Office2페이지의 정상 이름·원본 보존 확인은 확보했습니다. 연결 대기60초 계약과 기존 취소·종료 보호를 유지하고, 새 배포본의 연결을 확인합니다. |
| 2 | **한 화면의 기본 흐름 정돈**: 파일 추가, 출력 형식, 결과 폴더, 실행을 명확히 배치하고 고급 도구는 필요할 때 엽니다. 실제 조작과 키보드 접근을 확인합니다. |
| 3 | **형식별 이유 표시**: 선택한 입력과 출력 조합에 도구 필요, 수식·글꼴·매크로 주의와 변환 방향을 표시합니다. 탐지 없음은 보존 보장이 아닙니다. |
| 4 | **결과 이름의 실제 범위 완성**: 다중 페이지와 문서 결과 개수를 포함해 충돌 예정 이름을 표시하고, 외부 변경 시 새 이름을 안전하게 결정합니다. 긴 준비는 취소할 수 있어야 합니다. |
| 5 | **작업 복구와 결과 보관 확인**: 명시적 계속, 입력·결과 해시 재확인, 실패만 재시도, 변경된 결과 보호를 정상·중단·손상 경로에서 확인합니다. |
| 6 | **개인정보 경계 명료화**: 지원 형식과 선택 항목만 사본에서 정리하고, 공유 진단의 제외 항목을 저장 전 보여 줍니다. |
| 7 | **부드러운 화면**: 움직임은 상태 전환을 설명하는 곳에만 적용하고 축소 설정·라이트·다크·작은 화면의 조작 상태를 확인합니다. |
| 8 | **추가 기능은 사용 맥락부터 판단**: 영상·대규모 자동화 등은 위 13개 흐름의 안정성과 사용성을 확인한 뒤 실제 필요와 의존성을 검토합니다. 기능 수나 속도의 절대 우위는 주장하지 않습니다. |
