## HWP·HWPX 지원 범위

1.11.0은 대표 Office·ODF와 읽기 가능한 HWP·HWPX 입력의 변환 경로를 제공합니다. HWP·HWPX를 PDF·Word 등으로 읽는 경로는 격리 프로필의 확장 기능을 사용합니다. DOCX·TXT·HWP5·HWPX에서 HWP·HWPX로 새로 저장할 때는 앱에 포함된 별도 처리기를 사용하며, 단순 문단·굵게·기울임·병합하지 않은 직사각형 표·PNG/JPEG 그림으로 범위를 제한합니다. 지원하지 않는 복잡한 구조는 내용을 버린 채 성공으로 처리하지 않고 거부합니다. HWP5 쓰기는 실험적이며 글꼴·쪽 배치의 완전한 재현과 독립 뷰어의 시각적 동등성을 보장하지 않습니다. HWP 5 문서와 HWPX의 실제 검사 범위, 지원하지 않는 초기 Excel 2007 Beta2 XLSB, 외부 도구·암호·서식 제한을 [문서 지원 안내](../소스/1.10-문서지원안내.md)와 [문서51 독립 검사 요약](검증/문서51_독립검사_요약.json)에서 확인합니다.
