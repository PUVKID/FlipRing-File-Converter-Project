## 확인한 범위

- 기존 변환266조합·추가 안전3개와 새 EXE11모듈·설치624파일 대조 통과 기록을 유지합니다.
- JPG와 PDF 원본의 SHA-256이 시험 전과 같으며 실제 생성 PNG의 크기와 RGB 픽셀이 JPG와 같은 것을 별도 검사했습니다.
- 중앙 취소와 PDF 페이지 이동·새 저장은 사용자의 실제 조작 확인입니다. 새 저장 PDF의 위치와 내용을 다시 자동 대조했다고 표현하지 않습니다.
- 최초 최종 독립 검사163개 및 배포 대조는 통과했으나, 후속 부모 반복 실행은 검사78 실패로 완료를 차단했습니다. 이후 갱신된 전역 지침과 새 변경에는 새로운 동결·독립 검증이 필요합니다.
- GitHub의 원문·파일·링크는 연결 도구로 대조하며 웹 도구가 접근을 제한한 페이지의 브라우저 렌더를 직접 확인했다고 표현하지 않습니다.

## 공개 제외와 보류

개인 지침·프로필·연락처·메모리·원문 대화·사용자 운영 자료·비공개 실패 로그는 게시하지 않습니다. 실행·설치 바이너리와 대형 구성요소는 로컬 납품 폴더에 유지하며 이 문서 커밋에 넣지 않습니다. 공개 기록에는 제품 동작과 검증 범위만 요약합니다.
