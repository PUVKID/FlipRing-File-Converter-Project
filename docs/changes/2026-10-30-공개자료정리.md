## 🔗 동시 게시 문서 통합

동시에 반영된 문서 링크·자산 안내·기존 검증 범위 정정을 유지했습니다. 고정 커밋 `2cbab390a3b376e14a91de6d06bf1fb4d8b5d4a9`의 22개 문서를 기준으로 이어서 정리했습니다. 프로그램 소스와 실행·설치 파일은 바꾸지 않았습니다. 원격의 전체 차수 표와 이번 공개 정리 기록을 함께 연결하고, 현재 공개 파일 해시를 갱신했습니다.

검사 실행 구성과 기존 1.8.0 검증 결과를 보완한 후속 공개 파일 12개를 원문 그대로 보존했습니다. 출력 수집기와 13개 회귀 검사, GUI 검사 1개의 이벤트 관찰 보완 및 관련 해시·설명을 포함하며, 실행 코드와 설치 파일을 새로 수정하거나 기능 차수를 추가한 것은 아닙니다. 실제 검사 결과와 과거 검증을 재사용한 범위는 [검사 실행 구성 보완](../2026-11-02_검사실행구성보완.md)에 구분했습니다. 이번 통합 전의 공개 파일 변경 목록은 [이전 검수 파일 변경](../publication-review/이전검수파일변경-검증도구보완전.json)에 같은 바이트로 보존했습니다.
