# 문서 상대링크 정리 · 2026-10-31

중첩 보관본이 루트 저장소 문서를 복사하며 생긴 상대경로 오류를 정리했습니다. 확인한 링크 100개 중 76개는 같은 공개 경로 또는 정확한 원래 전체 경로 대응 자료로 연결했습니다. 공개에 없는 24개는 원래 라벨과 파일명을 글로 남겼습니다. 다른 차수의 동명 자료를 임의로 연결하지 않았습니다.

제품 코드와 실제 실행 경계·원본 법적 고지를 바꾸지 않았습니다. 변경된 문서·자료 색인의 현재 크기와 SHA-256 및 차수별 전체 비교를 갱신했습니다. 공개 검사기와 같은 파서로 기존 항목을 포함한 모든 상대링크를 검사합니다.
