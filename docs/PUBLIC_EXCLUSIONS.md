# 공개 제외 자료와 원문 보존

운영 로그·실패 기록·조율 자료·중간 조사 결과가 혼재한 작업 폴더와 이전 생성 설정은 현재 공개 사본에서 제외했습니다. 로컬 원문은 비공개로 보존하며 제품 역사 소스는 [전체 차수](REVISION_INDEX.md)에서 확인할 수 있습니다. 과거 Git 커밋은 변경하지 않았습니다.

공개 제외 파일은 [경로·크기·SHA-256·사유](source-materials/private-exclusions.json)로 구분합니다. 파일명에 있던 사적 식별자는 표시에서 가렸으며 정확한 원문 경로와 일대일 대응은 비공개로 보존합니다. 삭제 전 내용은 공개 패치에도 싣지 않습니다. 공개 가능한 변경은 공백·주석·개행을 포함한 전체 텍스트 차이로 제공합니다.

법적 조사 보조 소스 6개는 새 납품과 공개 사본의 사적 운영 보고 필드만 제거했습니다. 자료 다운로드·해시·상응 소스 검증 로직은 동일합니다. [원문과 공개 사본 해시](source-materials/legal-tool-transformations.json)를 구분합니다. 법적 고지·상응 소스 압축물은 변경하지 않았습니다. 새 자료에 맞춰 두 출하목록과 두 SHA 목록의 조사 도구 3개 항목만 실제 새 크기·해시로 갱신했습니다. 다른 원출처·archive·고지 항목은 동일하며 이전 출하목록과 도구 원문은 비공개로 보존합니다. 이 정리는 제품 실행 코드·기능의 변경을 뜻하지 않습니다. 설치 파일에는 정제된 자료를 다시 포함하며 새 배포 검증과 과거 기능 검증을 구분합니다.

일곱 설계문서에서는 개인 작업 정책·조율 배정·개인 플러그인 연결·자료 이동/정리 상황을 분리했습니다. 제품 사양과 실제 검사 성적·실패 사실은 유지하며 [정제 전후 크기·해시](source-materials/design-doc-transformations.json)를 구분합니다. 해당 원문과 원문 전체 차이는 로컬 비공개로 보존하고 공개 패치의 삭제 줄에는 싣지 않습니다.
