# 플립링 1.8 고정 창·영역 구분·세부 디자인 개선

사용자 최신 지시: 정상 동작을 유지하면서 칸과 구분선을 더 명확하게 하고, 창을 현재보다 조금 키워 고정 크기로 사용합니다. 앞선 자유 크기·반응형 확대 검토보다 이 고정 창 지시를 우선합니다. 화면·Windows 배율에 따른 글자와 아이콘 품질은 계속 확인합니다.

## 구현과 검증 기준

1.

기본 본문 크기는 기존 1080×780에서 1160×820 논리 픽셀로 조정하고 사용자의 창 크기 변경은 잠급니다.

배율은 Qt의 장치 독립 좌표를 따릅니다.

현재 화면의 사용 가능 영역보다 프레임이 크면, 화면 안에 들어가는 고정 크기로 한 번 맞추고 필요한 내용에는 스크롤 접근을 제공합니다.

모든 해상도에서 같은 물리 픽셀이나 모든 내용을 동시에 보이는 것을 보장하지 않습니다.
2. 흑백·회색과 SUIT를 유지합니다. 사이드 메뉴의 현재 위치 표시, 메뉴·본문 경계, 페이지 제목 아래 구분 선, 프리 셋·작업 목록·실행·원본/결과 비교 영역의 제목과 경계를 보강합니다. 과장된 장식과 계속 움직이는 배경은 추가하지 않습니다.
3. 버튼의 높이·간격·정렬, 라벨과 입력의 간격, 긴 한영 문구의 줄바꿈·도움말, 파일·페이지 목록의 선택 상태를 통일합니다. PDF·OCR 옵션과 페이지 편집·확대 화면, 기록·설정·도우미·정보·파일/폴더 선택창까지 확인합니다. 필요한 운영 기록과 라이선스·원본 보존을 유지합니다.
4. 이미지 미리 보기와 아이콘은 표시 크기·DPR을 구분해 그립니다. 정적 글자와 선은 Qt/QPainter의 고배율 처리를 사용하며 SVG 자산을 우선합니다. 실제 모니터 전환 시험과 QT_SCALE_FACTOR로 재현한 배율 시험을 구분합니다.
5. 기존 StateMark 모션 정지 검사 78의 간헐 실패를 먼저 계측합니다. 기존 400ms 모션과 420ms 후 완료 기대를 임의 완화하지 않습니다. 원인이 확인되면 유한 종 료·숨김·재진입·모션 줄이기 의미를 유지하는 최소 변경을 합니다. 실패 원문과 이전 통과 이력은 보존합니다.
6. 기존 GUI85·PDF/OCR28·일반 작업 20·PDF 편집 30과 Shift/OLE·중앙 취소·원본/설정/기록·프리 셋을 유지합니다. 변환 엔진·PDF 편집 모델·인증은 변경하지 않습니다. 엔진·검사 기 해시가 같으면 기존 266 변환 기록의 근거를 그대로 구분해 연결하며 새 코드로 재실행했다고 쓰지 않습니다.
7.

고정 창의 한영 6 화면·파일 선택 창·PDF 페이지 편집·확대·오류/빈 상태를 현재 렌더로 검사 합 니다. 100·125·150·200% 배율에서 DPR·글자 영역·버튼 접근·겹침·원본/결과 구분을 기록합니다.

작은 사용 가능 화면은 외곽 프레임과 스크롤 접근을 확인합니다.

실제 Windows의 배율을 자동으로 바꾸지 않습니다.
