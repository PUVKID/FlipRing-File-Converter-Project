# 2026-11-02 공개 상태 재확인

이번 기록은 기존 플립링 1.8.0의 소스·실행물과 공개 자료를 다시 연결하는 기록입니다. 새 기능 버전이나 새 빌드 결과를 뜻하지 않습니다.

아래 내용은 재개 초기의 실패와 당시 확인 범위를 보존한 기록입니다. 이후의 실행 구성 개정과 재검증 결과는 [후속 기록](2026-11-02_검사실행구성보완.md)에 구분합니다.

## 현재 소스와 기존 검증의 관계

- 공개 저장소의 7aa40ae0e52510645280913ed1054ea7313b5edd에서 새로 받은 소스와 보관 중인 Python 파일21개의 원문 바이트·SHA-256이 모두 같았습니다. 실행 코드를 새로 고치거나 기존 실행·설치 파일을 교체하지 않았습니다.
- 재개 후 별도 검증자는 현재 실행 파일에 내장된 앱 모듈12개를 소스의 코드 객체와 직접 대조하고, 출하 폴더와 실제 설치 폴더625파일의 크기·해시 일치를 확인했습니다. 소스21개는 엄격 UTF-8·문법과 기존 해시에 맞았습니다.
- 기존 100·125·150·200% 및 작은 화면의 7개씩 총35개 Qt 검사 보고서를 현재 소스9개의 해시와 다시 결합했습니다. 이 확인은 35개를 새로 렌더한 결과가 아닙니다. Qt 가상 화면과 실제 Windows의 모니터 배율·물리 조작을 구분합니다.
- 11월2일의 중앙163개 재검사는 30초 제한을 넘었고 출력 수집에서도 오류가 발생해 통과하지 못했습니다. 제한 초과 뒤 수집·정리를 포함한 관측 시간은 35.578초였습니다. 제품 소스는 바뀌지 않았으며, 현재625파일·내장12모듈·소스21개 대조의 통과와 중앙 재검사의 미통과를 구분합니다. 이 문서 보완을 앱 전체 최종 완료로 표시하지 않습니다.
- 이후 별도 순차 진단에서 GUI85개의 기존 통계·식별자·해시를 확인하고, PDF/OCR28개(22.016초)·일반 작업20개(24.641초)·PDF 편집30개(12.343초)를 각각 기존 27초 제한과 원래 기대값으로 실행해 모두 통과했습니다. 총163개 진단 결과이며 중앙 단일30초 실행의 통과를 뜻하지 않습니다. 첫 전체 검증의 미통과 이력을 유지합니다.
- 같은 날 중앙 병렬163개 실행의 재현에서는 기존30초 제한 초과와 함께 GUI 검사10의 `weights[0] = 1.0`이 기대값 `< 1`을 만족하지 못한 실패(`test_gui.py`653행), GUI 검사78의 애니메이션 상태 `Running != Stopped` 실패(2093행)가 실제 발생했습니다. 수집·정리를 포함한 관측 시간은30.375초였으며 두 번째 전체 검증 역시 미통과였습니다. 같은 실행의 기존 배포자료 대조는3.594초에 통과했습니다. 제품 코드와 검사 기준은 바꾸지 않았습니다. 앞선 GUI85개·순차78개 진단의 통과가 뒤의 두 assert 실패와 시간 초과를 덮지 않으며, 중앙 단일30초 실행의 통과나 앱 전체 완료로 확대하지 않습니다.
- 10월30일에 통과한 기존 GUI85·PDF/OCR28·일반 작업20·PDF 편집30, 총163개 기능 검사와 변환266개 기록은 당시 실행 범위입니다. 기존266개는 시작·종료·현재의 관련5파일 해시가 같다는 대조를 전제로 연결하며, 11월2일에 전부 새로 변환했다고 표현하지 않습니다.
- 1.8의 실제 설치·응답 창 확인과, 사용자가 정상 확인한 1.7의 물리 Shift/OLE·PDF 편집 결과는 별도 근거입니다. 이번 공개 자료 정리로 1.8의 물리 Shift/OLE·PDF 사용자 조작까지 재시험한 것은 아닙니다.

공개 소스에는 SUIT·나눔고딕 글꼴과 일부 화면 자산·OCR 언어 자료가 들어 있습니다. OCR/7-Zip 실행 바이너리와 모든 배포 자산이 포함된 것은 아닙니다. [실행 전 준비 범위](../README.md#quick-start)와 [1.8 변경 범위](versions/1.8.0.md)를 확인하세요. 기존 실패와 상태 표시의 이벤트 지연 관측은 뒤의 통과로 삭제하지 않았으며, 모든 하드웨어의 실시간 모션 종료나 오류 부재를 보장하지 않습니다.

## 작업 원본의 비교 기준

[고유 작업 코드·문서](../보존자료/작업소스/)의 622파일은 기존 작업 경로에 남은 개별 제품 코드·설계·사용법·실험 노트입니다. 동일한 이전 전체 폴더 스냅샷과 통일된 시간 순서가 확인되지 않아 이 묶음을 새로운 제품 버전으로 부르거나 가짜 직전 차수 diff를 만들지 않습니다.

제품 버전과 부분 기준본11개 및 현행 소스는 [전체 차수 표](REVISION_INDEX.md)의 실제 비교 자료를 사용합니다. 작업 원본은 [원래 경로·개별 바이트 수·SHA-256](source-materials/files.json)과 [수록 범위 설명](SOURCE_MATERIALS.md)으로 확인합니다. 이 자료의 추가·보존 판단과 제품 기능 개선의 검증은 서로 다른 근거입니다.
