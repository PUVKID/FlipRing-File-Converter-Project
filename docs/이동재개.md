# D드라이브 이동 후 작업 재개

확인일: 2026-10-24. 프로젝트 경로 이동 후에도 빌드·배포와 기존 사용자 데이터 경계를 유지한다.

프로그램·설치 파일·전체 소스·빌드 방법·라이선스를 같은 프로젝트 폴더에서 관리한다. 사용자 데이터는 운영체제의 표준 앱 설정 위치와 구분한다.

[내부 모션 설계](내부모션.md)의 기능·조작 범위를 유지한다. 실제 화면 연결과 검사 결과를 함께 확인한다.

활성 검사·빌드 명세는 실제 프로젝트 경로를 사용한다. 원본 실패 로그·과거 명령의 경로는 당시 관측이므로 일괄 치환하지 않는다. 당시 확인한 Python3.12.14·Qt6.12.0과 가상환경의 기반 런타임 경로를 구분하며, 경로 이동 뒤에는 빌드 방법에 따라 개발 환경을 재구성한다.

프로젝트의 프로그램 경로와 운영체제의 표준 앱 설정 위치를 구분하고 기존 사용자 설정·기록을 임의로 옮기지 않는다.

이전 생성 실행·설치 파일은 새 생성물의 검사 후 교체한다. 대형 중복 납품은 만들지 않으며 작은 소스 기준본과 실패·검증 기록을 보존한다. 새 코드의 실제 실행·설치·물리 Shift 검증과 기존 1.5 릴리스의 검증을 구분해 보고한다.
