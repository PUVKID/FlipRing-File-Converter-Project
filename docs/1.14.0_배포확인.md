# 플립링 1.14.0 확인 범위

기존 변환·PDF·OCR·작업 기록을 유지하면서 내부 화면의 간격·글꼴·테마 상태와 Rust 스타일 생성을 연결했습니다. 빌드와 소스 검사, Windows 설치와 실제 탐색기 조작은 아래에서 구분합니다.

| 대상 | 관측 | 상태와 범위 |
|---|---|---|
| 테마 연결 | 앱 기동·테마 변경에서 동봉 Rust 프로그램을 호출 | Python·Qt와 Rust의 실제 호출 확인; 파일 변환 전체를 Rust로 재작성한 것은 아님 |
| 글꼴 | 공식 나눔고딕 Bold 원문의 OS/2 굵기 700, 실제 9개 위젯의 글꼴과 굵기 확인 | 앱 내부의 글꼴 대체와 선택창·팝업의 굵기 연결을 보완 |
| 아이콘 | 라이트·다크와 선택 유무의 네 조합 | 확인한 파일 목록 아이콘 조합의 대비 11.65 이상; 화면 전체의 접근성 인증 수치가 아님 |
| 문서 도우미 | 격리된 문서 처리에서 앱 전용 경로 모듈의 불필요한 초기 로딩 제거 | 실제 HWPX→PDF 9.094초, 한글·표 내용과 원본 보존 확인 |
| 도우미 초기 준비 | 한 번의 45초 준비 제한 기록을 보존하고 같은 등록 도구를 별도로 진단 | 실제 등록은 후속 진단에서 16.607초 이내에 성공했습니다. 초기 준비 상한은 45초에서 120초로 조정했으며, 최초 시간 초과의 근본 원인과 45초 이후 자연 완료 시간은 미측정입니다. 30분 총기한·취소·소유 프로세스 회수·오류 전파는 유지합니다. |
| 전체 소스 | 확정 입력 1,007파일과 소스 ZIP 생성 | 실행·설치 파일의 기동·조작 확인과 구분 |
| 새 실행·설치 파일 | Inno 설치 프로그램 생성과 공식 배포 파일 검사 통과: 1,235개 파일·14.172초 | Windows 1.14.0 재설치 완료, 설치된 배포 파일 1,232개 SHA 일치. 새 설치본의 실제 Shift 드래그는 이번에 재실행하지 않음 |

시간은 해당 PC·입력에서의 실제 관측입니다. 다른 프로그램과의 속도 비교나 모든 입력의 처리 시간 보장이 아닙니다.

## 동결된 전체 소스

| 파일 | 크기 | SHA-256 |
|---|---:|---|
| `플립링-1.14.0-전체소스.zip` | 670,752,094바이트 | `f99235d0fe8a5e93560832e5a415c25791049ffd598f292cf2754c3692a8d34c` |

다운로드 주소의 실제 공개 여부는 릴리스 게시 후 확인합니다. 공개 Git의 선택 소스와 고객용 전체 소스 ZIP의 범위를 구분하며, 도우미·상응 소스·고지와 전체 재빌드 구성은 전체 소스에서 확인합니다.

## 계속 유지되는 지원 제한

| 항목 | 범위 |
|---|---|
| HWP·HWPX | 이전 차수의 지원 구조와 외부 도우미 조건을 유지; HWP5 저장은 실험적이며 복잡한 문서의 완전 보존을 보장하지 않음 |
| OCR | 결과 글자·표·읽기 순서를 원본과 대조해야 하며 자동 완전 인식을 보장하지 않음 |
| 서명 | 실행·설치 파일의 코드 서명 인증서는 적용되지 않음 |
| 성능 | Rust 연결 사실을 확인했으나 같은 조건의 전후 성능 비교는 미측정 |

## 생성한 실행·설치 파일

| 파일 | 바이트 | SHA-256 |
|---|---:|---|
| `FlipRing.exe` | 9,707,173 | `7d8d335c867a31e3770b51a7469bca04f22aacceb1b319e9472465f34baf4db9` |
| `FlipRing-Setup.exe` | 177,543,925 | `ca3fed5d064d0c44b9a599ae885ebf196bfce0304b1cd2b3597b2975992cab23` |

마우스 강조 수정이 포함된 실행 파일을 PyInstaller로 새로 생성했습니다. 소스 입력은 1,007파일이며 설치 후 배포 파일 1,232개의 원문 SHA가 빌드 출력과 일치했습니다. 별도 문서 도우미는 13,343바이트이며 SHA-256은 `d076c8bd1b1c677523b6041322151b2b0a9cada52c486a12f4f49a5af503421b`입니다. 파일 포함 검사는 설치 후 실제 변환과 화면 검사를 대신하지 않습니다.

## 마우스 강조와 새 설치본 확인

| 항목 | 실제 변경·관측 | 범위 |
|---|---|---|
| 마우스 강조 | 일반 박스 진입의 중복 반짝임 제거, 입력 칸·메뉴는 옅은 테두리와 배경 | 1px 안쪽 경계, 칸 자체 위치·크기는 유지 |
| 이탈과 재진입 | 220ms로 현재 밝기에서 사라짐, 밝기 0에서 즉시 이탈하면 대기 애니메이션 중지 | 소스 검사 7개와 별도 독립 검사 7개 통과; 실제 Qt 이벤트 루프 확인 포함 |
| 실제 이미지 변환 | 새 실행본 GUI에서 JPG→PNG, 80×60 결과 디코드 | 원본 SHA 보존 |
| 실제 문서 변환 | 새 설치본 GUI에서 HWPX→DOCX, 8,149바이트 | 시험 원본 section 전체 텍스트와 결과 document 전체 텍스트 정확 일치 |
| 중앙 취소 | 파일 선택 후 원형 미리보기 중앙 클릭으로 대기 상태 유지 | 물리 Shift/OLE 드래그 시험과 구분 |
| 재설치 | 기존 1.13 제거 후 기존 앱 데이터 초기화, 1.14 새 설치 | 프로젝트 원본과 고객 문서는 삭제 대상이 아님 |

빌드 중 설치 컴파일러와 새 실행본이 거의 같은 시각에 접근 위반으로 종료된 관측이 한 번 있었습니다. 원문을 보존한 뒤 동일 소스·실행부로 단독 기동·설치 컴파일·새 설치와 변환이 성공했습니다. 최초 충돌 원인은 확정하지 않았으며, 재발 가능성이 없다고 보장하지 않습니다. 새 설치본의 물리 Shift 드래그는 이번 확인 범위에 포함하지 않았습니다.
