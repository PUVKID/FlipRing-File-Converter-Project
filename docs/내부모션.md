# 플립링 내부 화면·조작 모션 확장

확인일: 2026-10-21. 사용자는 제시한 설계를 승인하고 파일·폴더 선택창과 모든 내부 화면·조작을 빠짐없이 같은 디자인과 부드러운 모션으로 연결하도록 요청했다. 현재 밝은 본문·어두운 사이드바·흑백·SUIT와 기존 기능은 유지한다.

이 작업은 기존 `studio-redesign-20261021`의 추가 범위다. 기존 수리8·입력보정6·실패·독립검증 이력을 초기화하지 않는다. 기존 정상 생성물은 새 생성물 검사 후 교체하며 대형 중복 납품을 만들지 않는다. 전체 소스·빌드 방법·라이선스·작은 실패/검증 기록을 보존한다.

## 범위와 성공 조건

- 파일 변환의 파일 선택·폴더 선택 및 PDF/OCR의 파일 추가는 공통 디자인과 열림·닫힘·위치 이동·항목 선택 피드백을 제공한다. 다중 파일, 한글 경로, 필터, 폴더 전용 선택, 키보드·Enter·Esc·취소 의미를 보존한다.
- 앱의 주 화면 다섯 개, 원형 메뉴, 팝업 메뉴·트레이 메뉴, 드롭다운, 입력/숫자 제어, 토글, 버튼, 도움말, 메시지 대화상자, 파일 목록, 기록 선택에 일관된 상태 전환을 적용한다. 구현자는 실제 위젯/함수별 적용 목록을 검증 자료에 남겨 누락을 대조한다.
- PDF/OCR의 옵션 전환·파일 추가/삭제/재정렬, 작업 진행·완료·실패·취소와 일반 파일 변환 상태에도 실제 동작에 반응하는 유한 모션을 적용한다. 실제 작업 상태와 표시값을 분리해 가짜 진행률을 만들지 않는다.
- 모션은 입력을 막거나 늦추지 않는다. 드롭 좌표와 클릭 영역은 고정한다. 빠른 재진입·반복 클릭·중간 취소·창 숨김·작업 종료에서 중복 실행, 잔상, 삭제 객체 접근과 남은 반복 타이머가 없어야 한다. 정지 상태에 불필요한 상시 고속 반복 그리기를 넣지 않는다.
- 한영 전환, 저장 스키마, 원본 보존, 실제 탐색기 Shift/OLE, 중앙 취소, 기록 왼쪽 더블클릭 파일 선택, 무료 배포·제작자 PUVKID, 변환 엔진·PDF/OCR 정확도/권한 경계를 보존한다.
- Windows 탐색기 자체, 운영체제 창 프레임·시스템 권한 화면과 다른 앱은 변경하지 않는다. 모든 하드웨어의 일정한 프레임 속도나 운영체제가 그리는 모든 동작의 변경을 보장하지 않는다. 최종 보고는 실제 수정한 앱 표면과 직접 시험 범위를 명시한다.

## 검증과 납품

기존 GUI69·PDF/OCR28의 기대 동작을 유지하고 공통 선택창/메뉴/진행표시/모션의 중간 프레임·종료·재진입·키보드 회귀를 추가한다. 독립 검증자는 구현자와 다른 child로 최종 소스와 적용 목록을 대조한다. 최종 실행·설치 파일을 실제 Windows에서 실행해 선택창과 모션을 관찰하며 물리 Shift는 자동 모의 입력과 구분한다.

사용자가 삭제한 개발 환경과 빌드 캐시는 고정 의존성으로 복원한다. 현재 확보된 공간을 실측하며 작업한다. 납품은 바탕화면 플립링 폴더 하나의 실행 프로그램·설치 파일·전체 소스·빌드 방법·라이선스로 유지한다. 사용자가 검토할 수 있는 실제 화면과 코드에서 렌더링한 모션 미리보기를 보관한다.
