# 플립링 화면 구조 전면 재설계

확인일: 2026-10-21. 작업: studio-redesign-20261021.

사용자는 1.4의 기능 정상 확인 뒤에도 기존 프로그램의 구성 자체가 오래된 느낌이라고 지적하고, 최근 데스크톱 앱처럼 화면 전체를 모션 그래픽의 인상으로 다시 설계하라고 요청했다. 이는 색과 글꼴 조정만의 수정에서 더 나아간 명시적인 전체 프런트엔드 재설계 요구다. 이전 기능·검증·실패 원문은 보존한다.

## 디자인과 실제 사용

- 기존 460×600 설정 탭 중심 구성에서 벗어나 충분한 폭의 작업 공간과 사이드 내비게이션으로 정보 구조를 바꾼다. 첫 화면은 실제 파일 선택·드롭과 변환을 위한 작업 화면이다. 과도한 장식이나 존재하지 않는 통계는 표시하지 않는다.
- 현재 SUIT와 한영 설정을 유지한다. 밝은 작업 화면과 어두운 사이드바를 기본 제안으로 두고 사용자 분위기 선택을 반영한다. 기존 흑백·회색 요청은 유지하며 유색 강조를 임의 추가하지 않는다.
- 헤더, 파일 작업 영역, 설정 영역, 작업·기록 상태를 명확한 시각 계층과 정돈된 여백으로 나눈다. PDF·OCR와 기록·외부 도우미·정보 화면까지 일관되게 설계한다. 설치/실행되는 데스크톱 제품에 직접 구현한다.
- 원형 메뉴는 현대적인 타이포그래피·상태 표현과 연속적인 등장/선택/종료를 제공한다. 드롭 영역은 고정하고 원본 보존·중앙 취소·중복 변환 차단을 유지한다.
- 내비게이션 선택, 콘텐츠 등장, 버튼 상태, 드롭 상태, 작업 상태를 짧고 일관된 유한 애니메이션으로 연결한다. 움직임 때문에 입력이 막히거나 글자가 읽히지 않아서는 안 된다. 이전 상태에서 자연스럽게 재진입하고, 숨김·종료·완료 시 자원을 정리한다. 사용하지 않을 때 상시 높은 주사율로 반복 그리기하지 않는다.

## 기능·저장·범위

무료 배포, 제작자 PUVKID, 변환 엔진, PDF 편집·한영 OCR·검색 PDF·TXT·Word·Excel, 설정·기록 데이터·트레이·자동 시작·탐색기 Shift 드래그·기록 왼쪽 더블클릭 파일 선택을 유지한다. 기존 소개 네 줄과 인증·체험·만료·횟수 제한은 다시 넣지 않는다.

최종 납품은 바탕화면 플립링 폴더 하나에 실행 프로그램·설치 파일·전체 소스·빌드 방법·라이선스를 둔다. 사용자가 허용한 기존 생성 실행/설치 파일 교체는 용량을 실측하며 진행한다. 전체 런타임·설치 파일의 대형 중복 사본을 만들지 않는다. 이전 작은 소스·검사·실패·해시 근거는 work/evidence에 보관한다. 이 최신 제품별 저장 요구는 일반 차수 규칙보다 우선한다.

## 성공 조건

원본과 시각적으로 확연히 다른 화면 구조, 실제 연결된 변환 및 PDF/OCR 조작, 모든 한영 텍스트, 키보드/선택/취소/원본/기록/트레이 경로를 확인한다. 기존 검사의 기능 의미를 보존하고 새 화면 구조에 맞는 회귀·중간 모션·빠른 재진입·효과 수명 검사를 수행한다. 변경된 레이아웃에 맞게 실제 좌표와 대상 위젯을 찾되 기존 동작 기준·원본 해시를 약화하지 않는다.

화면 캡처로 디자인을 직접 검토한 뒤 새 실행/설치 파일을 만들고 실제 Windows 창에서 확인한다. 오프스크린 QWidget.grab은 native 투명 효과의 잔상을 숨길 수 있으므로 실제 창에서도 빠른 페이지 전환과 종료 프레임을 관찰한다. 별도 verifier가 최종 소스·실행물·명세를 다시 검사한다. 물리 Shift 입력과 사용자 확인, 자동 모의 입력의 범위는 구분한다.

## 사용자 확정 방향
사용자는 밝은 본문과 어두운 사이드바를 선택했다. 현재 사용하는 ChatGPT/Codex의 절제된 정보 계층과 정돈된 본문 구성을 참고하되 제품 브랜드·로고를 복사하지 않는다. 모션 그래픽은 작은 장식이 아니라 눈에 보이는 중심 시각 요소이며, 사용자가 단순하고 깔끔하게 쓰면서 파일 드롭·선택·완료의 반응을 느끼도록 한다.
사용자가 외부 플러그인이나 도구의 직접 활용을 요청했다. 플러그인 관리 스킬로 검색한 Product Design은 미설치 상태여서 설치 제안을 보냈다. 사용자 연결 확인 전에는 해당 디자인 도구를 사용했다고 표현하지 않는다. 핵심 구현은 연결 대기로 중단하지 않는다. 공식 Lucide SVG 아이콘을 고정 커밋과 원문 라이선스·출처·해시로 도입하며 중심 링 그래픽은 앱 전용 코드 벡터로 구현한다.

플러그인 상태 갱신(2026-10-21): 사용자가 디자인 플러그인을 미리 설치하도록 요청한 후 실제 검색 결과 Product Design installed=true를 확인했다. 로컬 index/user-context/audit 및 관련 원칙을 읽고 저장 맥락 사전 점검을 실행했으며 저장 맥락은 없었다. 이번 앱의 실제 작업 흐름을 캡처해 검토하는 audit 절차를 적용한다. Figma·MagicPath·Canva·Adobe·Runway·Higgsfield는 설치/연결 항목을 가져왔으며 확인 전 설치 완료로 표현하지 않는다. 제품 구현은 Qt 데스크톱 앱을 유지한다.

사용자 추가 범위: 별도 로그인/계정 연결이 필요한 외부 디자인 도구는 제외한다. 이미 로컬 설치 확인한 Product Design과 기본 제공 기능·Lucide·Qt를 사용하며 제품 사용자에게 로그인 절차를 추가하지 않는다.
