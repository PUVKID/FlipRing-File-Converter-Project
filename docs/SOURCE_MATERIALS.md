# 원본 제품자료와 압축 소스

기존 모든 차수는 [첫 화면 차수표](../README.md)에서 탐색합니다. 이번에는 코드·제품 설정·사용법·설계·실험 기록·자체 제작 리소스·라이선스를 원본 경로와 함께 보강했습니다. 아래는 기존 공개 기준과 바이트가 다른 제품자료 977개 목록입니다. 전체 차수의 공개 파일은 각 차수 비교 명세에 별도로 있습니다.

| 차수·위치 | 추가·변경 자료 수 |
|---|---:|
| SHA256SUMS.txt | 1 |
| docs | 4 |
| offscreen-monitor.json | 1 |
| 보존자료 | 623 |
| 소스 | 136 |
| 프로그램 | 212 |

ZIP은 중앙 목록과 경로 탈출·링크·암호화·크기 경계를 검사하고 소스 멤버를 실제 읽었습니다. 기존 공개 파일과 바이트 또는 BOM·개행만 같은 멤버는 대응 링크로 남기고, 고유 소스는 `압축원본소스`에 보존했습니다. 실행 바이너리·캐시·실제 인증 자료·실제 운영 DB·실거래 계좌 자료·원작 추출 표현 자산은 제외했습니다. 각 ZIP의 모든 멤버 판단은 비공개 검토 명세에, 공개 대응 멤버는 아래 JSON에 있습니다.
