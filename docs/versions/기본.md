# 기본 · 원형 메뉴·트레이와 변환·PDF 처리의 현재 구조

[프로젝트 소개](../../README.md) · [전체 차수 비교](../VERSIONS.md) · [원본 보관 폴더](../../%EC%86%8C%EC%8A%A4/)

**자료 상태: 현재 구조·숫자 차수 없음**

## 🎯 이 자료의 목적

이 문서는 원형 메뉴·트레이와 변환·PDF 처리의 현재 구조에 관한 안내입니다. 아래 설명은 보관된 소스의 동작과 차이를 정리했으며 새 실행 결과를 뜻하지 않습니다.

## ✨ 구현과 변경 내용

app.py는 Shift를 누른 채 파일을 끄는 입력을 감시하고 원형 메뉴·트레이·작업 큐를 연결합니다. 일반 변환과 PDF 작업은 각각 단일 작업 스레드이며 두 큐를 동시에 실행하지 않습니다.

근거: [MainWindow (1~1498행)](../../%EC%86%8C%EC%8A%A4/app.py#L1-L1498)

engine.convert는 파일 종류별 도구를 선택하고 같은 드라이브 임시 폴더에서 처리한 뒤 새 이름으로 이동합니다. 압축의 상위·절대 경로와 링크를 검사합니다.

근거: [convert (1~447행)](../../%EC%86%8C%EC%8A%A4/engine.py#L1-L447)

pdf_tools와 pdf_panel은 페이지 추출·삭제·회전·압축·OCR 출력 옵션을 처리합니다. PDF 결과는 배타적 생성으로 덮어쓰기를 피하며 OCR의 행·열은 글자 위치에서 추정합니다.

근거: [PdfToolError (1~644행)](../../%EC%86%8C%EC%8A%A4/pdf_tools.py#L1-L644) · [_Bridge (1~498행)](../../%EC%86%8C%EC%8A%A4/pdf_panel.py#L1-L498)

studio_ui·ui_motion은 화면과 유한 애니메이션을 구성합니다. 최근 기록은 입력·출력·오류를 최대 200개 보관하므로 운영 파일 경로를 포함할 수 있습니다.

근거: [svg_icon (1~403행)](../../%EC%86%8C%EC%8A%A4/studio_ui.py#L1-L403) · [FeedbackOverlay (1~757행)](../../%EC%86%8C%EC%8A%A4/ui_motion.py#L1-L757) · [MainWindow (1~1498행)](../../%EC%86%8C%EC%8A%A4/app.py#L1-L1498)

## 🔄 입력·처리·출력

| 단계 | 내용 |
| :--- | :--- |
| 입력 | 로컬 파일 드롭·출력 형식·PDF 페이지/인식 옵션 |
| 처리 | app의 원형 메뉴/큐 → engine 또는 pdf_tools → 작업 결과 반영 |
| 출력 | 새 변환 파일·PDF/OCR 결과·최근 변환 기록 |

## 🔎 이전 보관본과 비교

비교할 숫자 차수 이력이 없어 현재 구성의 역할을 설명합니다. 폴더명이나 파일 수만으로 이전 릴리스 대비 새 기능이라고 부르지 않습니다.

## 🚀 실행 경로와 제약

소스/app.py가 GUI 진입점이며 engine.py와 pdf_tools.py가 처리를 맡습니다. PySide6와 각 변환 라이브러리, 작업에 따른 FFmpeg·Tesseract 등 외부 도구가 필요합니다. 도움 도구 화면은 설치 명령을 복사하며 자동 설치하지 않습니다. OCR 표·배치의 완전 복원이나 압축 후 크기 감소를 보장하지 않습니다. 이번 문서 작업에서는 GUI·변환·OCR을 실행하지 않았습니다.

숫자 차수 폴더가 없는 현재 구조입니다. 기본은 문서상 분류이며 새로 만든 1차나 제품 릴리스 번호가 아닙니다.

더 자세한 준비 조건·시험 범위·주의점은 [README](../../README.md#quick-start)와 [차수별 파일 구성](../VERSIONS.md)를 함께 확인해 주세요.
