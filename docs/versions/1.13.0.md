# 플립링 1.13.0 · 다섯 읽기 수준

**아래는 제작 시점 소스와 기능 검토 범위에 근거한 설명입니다.** 최신 실행·설치 확인은 [배포 확인 범위](../1.13.0_배포확인.md)에서 구분합니다. Office 문서 결과 이름 미리보기의 이전 연결 시간 초과를 수정했습니다. 소스 검사에서 2페이지 예정 이름과 실제 결과 2개, 원본 해시 보존 및 미리보기 시 결과 미발행을 확인했습니다. 실행·설치 파일과 전체 소스 ZIP은 빌드했습니다. 냉간 시작의 세부 원인은 측정하지 않았습니다. 기존 흑백 기반 화면과 SUIT 글꼴, 라이트·다크·시스템 테마와 움직임 축소를 유지합니다.

아래에서 원하는 수준을 선택하세요. 각 수준은 같은 13개 기능을 다루며 설명의 깊이가 다릅니다.

| 읽기 수준 | 설명 |
|---|---|
| [LEVEL 1 · 처음 사용하기](#user-content-reading-level-1) | 쉬운 말로 사용 순서와 주의점을 살펴봅니다. |
| [LEVEL 2 · 기능 이해하기](#user-content-reading-level-2) | 입력과 결과, 선택 조건을 연결합니다. |
| [LEVEL 3 · 직접 활용하기](#user-content-reading-level-3) | 설정과 실행 흐름, 주요 함수와 실패 경계를 살펴봅니다. |
| [LEVEL 4 · 구조 분석하기](#user-content-reading-level-4) | 처리 단계와 상태 보존 방식을 분석합니다. |
| [LEVEL 5 · 구현과 한계](#user-content-reading-level-5) | 자료 구조·검사 경계·재현 시 확인할 조건을 설명합니다. |

| 호환 안내 | 호환 안내 탭에서 파일과 바꿀 형식을 고른 뒤 호환 확인을 누릅니다. | 글꼴·수식·매크로 안내를 읽습니다. 발견하지 못한 문제까지 없다고 보장하지 않습니다. |

| 폴더 구조 | 폴더 추가로 폴더를 넣고 결과 폴더를 선택합니다. 필요한 경우 확장자 필터를 씁니다. | 하위 폴더의 상대 구조를 따릅니다. 연결된 파일·폴더는 따라가지 않으며 건너뛴 항목을 확인합니다. |
| 메일·인쇄·웹 | 빠른 작업 목록에서 용도를 고르고 필요하면 설정을 바꿔 저장합니다. | 메일은 JPG 품질80·너비1600px·1MiB 목표, 인쇄는 PDF 품질95·크기자동·목표 없음, 웹은 WebP 품질80·너비1920px·512KiB 목표입니다. 목표 달성은 보장하지 않습니다. |
| 개인정보 선택 제거 | 개인정보 탭에서 파일을 고르고 메타데이터 탐지 후 지울 항목과 저장 폴더를 선택합니다. 선택 제거 사본 저장을 누릅니다. | PDF·OOXML·JPEG·PNG의 지원 항목만 새 사본에서 제거합니다. 원본과 본문·첨부·댓글은 별도로 확인하세요. |
| OCR 순서 | OCR 교정에서 문자 인식을 실행하고 인식 위치와 읽기 순서 보기를 켭니다. 번호나 목록으로 위치를 살피고 글을 고칩니다. | 원본에 보이는 글자와 표를 직접 비교하세요. 누락을 모두 자동으로 찾지는 못합니다. |
| 이름 미리보기 | 파일·작업·결과 폴더를 정한 뒤 이름 미리보기를 누릅니다. | 충돌을 고려한 예정 이름입니다. 실행 중 다른 파일이 생기면 이름이 달라질 수 있고 Office 연결 시간 초과는 수정 후 소스 검사에서 확인했으며 배포 실행 파일은 미검증입니다. |
| 중단 후 이어하기 | 다시 시작한 뒤 기록을 살펴보고 계속을 직접 누릅니다. | 자동으로 실행되지 않습니다. 입력이나 결과가 바뀌면 다시 확인해야 하며 손상된 기록은 보존합니다. |
| 공유 진단 | 공유 진단 미리보기에서 내용을 읽고 저장하거나 취소합니다. | 버전·상태·형식·오류 분류만 담으며 파일명·경로·본문·오류 원문·실제 설정값은 제외합니다. 일반 요약 저장과 다릅니다. |

### 처음 보는 용어

| 용어 | 쉬운 뜻 | 사용 중 확인할 점 |
|---|---|---|
| KiB·MiB | 파일 크기 단위입니다. 1KiB는1,024바이트이고 1MiB는1,024KiB입니다. | 목표1MiB와512KiB는 원하는 크기이며 실제 달성을 보장하지 않습니다. |
| OCR | 사진이나 스캔에 그려진 글자를 읽어 편집 가능한 글로 옮기는 문자 인식입니다. | 원본 글자·표와 비교해 잘못 읽거나 빠진 곳을 직접 고칩니다. |
| OOXML | DOCX·XLSX·PPTX처럼 Word·Excel·PowerPoint가 사용하는 문서 묶음 형식입니다. | HWP·HWPX와 다릅니다. 이 안내의 개인정보 선택 제거 지원 형식도 구분합니다. |
| 메타데이터 | 작성자·촬영 정보처럼 본문 외에 파일 안에 붙은 정보입니다. | 선택한 항목만 사본에서 지웁니다. 본문·첨부·댓글 안의 개인정보는 별도입니다. |
| 매크로 | 문서 안에서 자동 작업을 수행하는 코드입니다. | 다른 형식으로 바꾸면 유지되지 않을 수 있어 호환 안내와 실제 결과를 살펴봅니다. |
| 변환 도우미 | 일부 문서를 읽고 저장하기 위해 추가로 쓰는 프로그램입니다. | 필요한 도구가 없으면 앱 안내에서 설치 상태를 확인합니다. |

예를 들어 `회의록.docx`2페이지를 PNG로 바꾸려면 파일을 추가하고 PNG와 결과 폴더를 고른 뒤 이름 미리보기를 누릅니다. 예정 결과2개를 확인하고 실행하면 각 페이지 이미지가 새 이름으로 저장됩니다. 원본 Word 파일은 그대로 두고 결과 이미지의 글자와 표를 열어 확인합니다. 글자가 사진으로만 있는 PDF에서는 OCR을 실행한 뒤 위치 번호와 실제 원본을 비교해 교정합니다.

원본은 수정하지 않고 결과를 새 이름으로 만듭니다. **목표 용량과 호환 안내는 보장 값이 아니므로** 결과를 실제 용도에 맞게 열어 확인하세요.

## LEVEL 2 - Explorer

[프로젝트 같은 수준](https://github.com/PUVKID/FlipRing-File-Converter-Project/blob/main/docs/읽기안내/레벨2.md) · [이전 차수 같은 수준](https://github.com/PUVKID/FlipRing-File-Converter-Project/blob/main/docs/versions/1.12.1.md#user-content-reading-level-2) · [프로필 같은 수준](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨2.md)

| 기능 | 사용·조건 | 확인·제한 |
|---|---|---|
| 전후 비교 | 빠른 작업에서 원본·결과를 보거나 전후 비교 탭에 두 파일을 지정합니다. | 페이지 미리보기와 추출 텍스트 차이를 참고합니다. 문서 변환 도우미와 복잡한 배치의 한계를 확인합니다. |
| 호환 안내 | 파일과 출력 형식을 선택하고 글꼴·수식·매크로 흔적과 지원 안내를 확인합니다. | 제한된 내부 검사이며 표시되지 않은 개체의 보존을 보장하지 않습니다. |
| 실패만 재시도 | 대기열에서 실패 작업을 다시 요청합니다. | 완료 입력은 재변환하지 않고 남은 입력을 사용합니다. ZIP 단계가 남았다면 결과를 다시 묶습니다. |
| 목표 용량 | 이미지·PDF 출력에서 KiB 목표와 품질을 설정합니다. | 유한한 후보 중 결과를 만들며 목표 미달성을 표시하고 결과는 보존합니다. |
| 사용자 작업 저장 | 형식·품질·크기·이름·필터 등을 이름 붙여 저장합니다. | 저장 설정과 실행할 입력·결과 경로를 구분합니다. |
| 작업 묶음 정리 | 작업이 만든 결과를 선택해 보관하고 필요할 때 복원합니다. | 소유 기록과 SHA-256을 대조합니다. 변경이나 이름 충돌은 덮어쓰지 않습니다. |
| 폴더 구조 | 폴더 입력에서 상대 경로를 보존해 출력합니다. | 연결점과 숨김·임시 항목을 자동으로 따라가지 않으며 건너뜀을 확인합니다. |
| 메일·인쇄·웹 | 메일 JPG 품질 80, 인쇄 PDF 품질 95, 웹 WebP 품질 80을 출발점으로 사용합니다. | 각각 1600px·1MiB, 크기 자동·목표 없음, 1920px·512KiB입니다. 변환 내용과 결과 크기는 직접 확인합니다. |
| 개인정보 선택 제거 | 지원 파일의 탐지된 키를 선택하고 새 사본을 저장합니다. | PDF·OOXML·JPEG·PNG만 지원하며 본문·첨부·댓글 제거 기능이 아닙니다. 원본은 보존합니다. |
| OCR 순서 | 인식된 단어의 페이지별 번호·위치와 교정 텍스트를 함께 봅니다. | 낮은 확신도와 번호 없는 영역을 원본과 비교합니다. 자동 누락 탐지는 보장되지 않습니다. |
| 이름 미리보기 | 결과 폴더의 기존 이름과 묶음 내 충돌을 고려해 예정 이름을 표시합니다. | PDF 페이지 수와 문서의 임시 변환 결과 수를 이용합니다. Office 경로는 시간 초과 수정 후 소스 검사에서 2페이지를 확인했습니다. 배포 실행 파일은 미검증이며 외부 변경은 새 번호를 만들 수 있습니다. |
| 중단 후 이어하기 | 기록을 불러온 뒤 상태를 확인하고 계속을 누릅니다. | 입력·완료 결과 해시와 개수를 확인하고 변경 또는 불확실한 발행은 재확인 상태로 둡니다. 자동 실행하지 않습니다. |
| 공유 진단 | 미리보기 후 허용된 진단 정보를 저장합니다. | 버전·상태 집계·허용 형식·오류 분류만 포함합니다. 일반 요약에는 상세 정보가 있을 수 있습니다. |

세 도구 탭은 **호환 안내·개인정보·전후 비교**로 나뉩니다. 개인정보 정리 후에도 파일 내용과 첨부 자료를 직접 검토해야 합니다.

## LEVEL 3 - Practitioner

[프로젝트 같은 수준](https://github.com/PUVKID/FlipRing-File-Converter-Project/blob/main/docs/읽기안내/레벨3.md) · [이전 차수 같은 수준](https://github.com/PUVKID/FlipRing-File-Converter-Project/blob/main/docs/versions/1.12.1.md#user-content-reading-level-3) · [프로필 같은 수준](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨3.md)

| 기능 | 사용·조건 | 확인·제한 |
|---|---|---|
| 전후 비교 | `compare_files`는 추출 텍스트를, `compare_documents`는 선택 페이지의 실제 렌더와 텍스트 차이를 사용합니다. | 서로 다른 형식·서식·배치의 완전한 의미 동등성은 판정하지 않습니다. |
| 호환 안내 | `compatibility_report`는 입력·목표 형식과 글꼴·수식·매크로 등 제한된 흔적을 안내합니다. | 보호 문서와 외부 엔진, 탐지 범위를 확인하며 탐지되지 않음 결과를 완전 보존으로 해석하지 않습니다. |
| 실패만 재시도 | `retry_failed`는 완료 입력을 제외하고 남은 기록을 큐에 넣습니다. | `bundle_pending`에서는 기존 결과 해시를 확인해 ZIP 단계만 다시 수행합니다. |
| 목표 용량 | `run_action`이 `execute_workspace`에 최대 바이트와 품질을 전달합니다. | 이미지·PDF 후보 탐색 후 결과 크기를 확인하고 미달성 경고를 남깁니다. |
| 사용자 작업 저장 | `ActionStore`가 형식·품질·크기·템플릿 등 설정을 검증해 저장합니다. | 입력과 결과 경로는 작업 설정에 포함하지 않으며 중복 이름과 손상된 저장을 확인합니다. |
| 작업 묶음 정리 | `OutputLedger`가 소유 결과를 해시 대조 후 보관하고 `undo`로 복원합니다. | 선택 작업의 결과를 대상으로 하며 변경·이름 충돌은 보호합니다. 보관은 영구 삭제가 아닙니다. |
| 폴더 구조 | `collect_inputs`가 상대 경로를 기록하고 `run_action`이 결과 하위 경로에 사용합니다. | 경로 이탈과 연결점을 거부하고 필터·건너뛰기를 표시합니다. |
| 메일·인쇄·웹 | `BUILTINS`의 JPG 80·1600px·1MiB, PDF 95·자동 크기, WebP 80·1920px·512KiB를 선택합니다. | 목적별 출발 설정이며 목표 크기나 인쇄 품질을 보증하지 않습니다. |
| 개인정보 선택 제거 | `metadata_report`의 탐지 키를 선택해 `strip_metadata`가 사본을 만듭니다. | PDF·OOXML·JPEG·PNG만 지원하며 본문·첨부·댓글은 대상이 아닙니다. |
| OCR 순서 | `recognize_editable`의 단어별 페이지·좌표·확신도를 화면의 번호와 연결합니다. | 편집 텍스트를 유지하고 번호 없는 내용을 사용자가 확인합니다. 누락 자동 검출은 보장하지 않습니다. |
| 이름 미리보기 | `preview_output_names`는 기존 이름과 묶음 예약, 실제 페이지·임시 변환 결과 수를 고려합니다. | 실행 시 배타 생성으로 재충돌을 처리합니다. Office 연결 시간 초과 수정 후 소스 검사에서 2페이지를 확인했으며 배포 실행 파일은 미검증입니다. |
| 중단 후 이어하기 | `recover_jobs`는 입력과 결과의 SHA-256·결과 수를 대조해 상태를 복구합니다. | 복구 후 사용자가 계속을 눌러야 합니다. 변경·불확실한 결과는 `review`로 확인합니다. |
| 공유 진단 | `diagnostic`이 허용된 버전·상태·형식·분류만 새 객체로 구성합니다. | 경로·파일명·본문·원문 오류·실제 설정은 제외합니다. 일반 요약 내보내기는 별도입니다. |

재현 시 같은 입력·설정·외부 도구·저장 위치를 확인하세요. 이 문서의 함수 연결은 정적 대조이며 **실행 통과 근거가 아닙니다.**

## LEVEL 4 - Advanced

| 목표 용량 | `workspace_core._size_candidate`가 실제 후보를 비교하고 `constraints_met`과 경고를 전달합니다. | 크기는 입력과 인코딩에 따라 달라지므로 요구치 이하를 항상 약속하지 않습니다. |

| 메일·인쇄·웹 | 기존 `BUILTINS`와 동일한 설정 구조에 세 용도를 추가합니다. | 메일 1MiB·웹 512KiB는 목표이며 인쇄 PDF는 최대 크기가 없습니다. |

| OCR 순서 | TSV 단어 위치·페이지·확신도를 정규화해 페이지의 인식 순서와 연결합니다. | 원본에서 인식되지 않은 요소는 번호가 없을 수 있으며 사람이 대조해야 합니다. |
| 이름 미리보기 | PDF의 페이지 수 및 문서 임시 변환 출력 수를 얻고 기존 파일·예약 이름을 고려합니다. | Office 연결 시간 초과는 수정 후 소스 검사에서 확인했습니다. 배포 실행 파일은 미검증이며 예정 시점과 발행 시점의 외부 변경은 다를 수 있습니다. |
| 중단 후 이어하기 | `QueueJournal`이 상태·체크포인트·소유권을 저장하고 `recover_jobs`가 파일을 다시 확인합니다. | 사용자의 계속 전 자동 실행하지 않습니다. `waiting`·`completed`·`review` 전이는 해시·결과 개수에 좌우됩니다. |
| 공유 진단 | 상태와 허용 확장자 집계 및 고정 오류 분류만 생성합니다. | 상세 오류와 설정·경로·파일명을 내보내지 않습니다. 일반 작업 요약은 다른 기능입니다. |

원본과 기존 결과를 덮어쓰지 않는 방식, 실패·취소 시 임시 산출물 처리, 손상 기록 보존을 함께 평가해야 합니다. 정적 구조만으로 모든 입력과 환경의 안전성을 입증할 수 없습니다.

| 폴더 구조 | `safe_path`는 조상 재분석 지점을 확인하고 `collect_inputs`의 상대 경로를 출력에 전달합니다. | 폴더 연결·경로 탈출 거부와 충돌 시 안전한 이름을 유지합니다. |
| 메일·인쇄·웹 | 기본 작업은 각각 JPG 80·1600px·1MiB, PDF 95·자동 크기·목표 0, WebP 80·1920px·512KiB입니다. | 품질과 최대 크기는 각 엔진·입력에 따라 결과가 달라집니다. 0은 제한 없음입니다. |
| 개인정보 선택 제거 | `metadata_report`가 PDF·OOXML·JPEG·PNG의 탐지 항목을 열거하고 `strip_metadata`가 선택된 키로 사본을 만듭니다. | 본문·첨부·댓글 제거가 아닙니다. PDF는 문서 객체를 복제하며 전자서명 유효성·응용 프로그램별 동일 동작을 보장하지 않습니다. |
| OCR 순서 | Tesseract TSV에서 유효한 단어 좌표·확신도를 수집하고 실제 순서 번호와 위치를 연결합니다. | 낮은 확신도도 후보일 뿐이며 인식하지 못한 글자·표는 원본과 대조해야 합니다. |

| 중단 후 이어하기 | `recover_jobs`는 입력 SHA-256, 예상 결과 개수와 각 결과 SHA-256을 검사합니다. 무결한 대기는 `waiting`, 일치한 결과는 `completed`, 나머지는 `review`입니다. | 이전 `running` 작업은 자동 실행하지 않고 대기로 돌립니다. 손상 기록을 덮어쓰지 않으며 사용자의 계속 조작이 필요합니다. |
