## LEVEL 1 - Beginner · 목적부터 결과 확인까지

[같은 수준 프로젝트](../읽기안내/레벨1.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨1.md) · [LEVEL 1 - Beginner](#reading-level-1) · [LEVEL 2 - Explorer](#reading-level-2) · [LEVEL 3 - Practitioner](#reading-level-3) · [LEVEL 4 - Advanced](#reading-level-4) · [LEVEL 5 - Expert](#reading-level-5) · [프로젝트 첫 화면](../../README.md)

버튼 모션은 마우스를 올리거나 누를 때 배경·테두리가 바뀌는 모습입니다.

이 부분본에는 `ButtonMotion`과 `SoftTabs`가 정의된 app 코드와 GUI 검사가 남아 있습니다.

버튼 효과를 손보기 전 기준을 읽을 때, 예쁜 변화뿐 아니라 **누를 위치와 실제 클릭 동작**을 함께 확인합니다.

버튼이 움직여 보인다고 눌러야 할 자리가 따라 바뀌어서는 안 됩니다.

예를 들어 변환 버튼 위에 마우스를 올리고 누르는 상황을 비교 대상으로 잡습니다. 그림 변화는 모션 코드, 클릭 처리는 기본 버튼의 책임입니다. 이 자료에서 얻는 것은 그 구분을 읽을 근거이며 새 설치본에서 확인한 화면 결과가 아닙니다. 남아 있는 app·test_gui·README·파일목록만 보존 범위로 삼습니다.

<a id="level-1-section-3"></a>
### LEVEL 1 · 입력·처리·출력

이 절의 입력은 변환할 사진이 아니라 보존된 화면 코드와 GUI 검사입니다. 버튼 위로 마우스 이동·누름·키보드 포커스을 코드에서 따라가고, 출력은 변경 전·후의 비교 근거입니다. 버튼을 한 번 눌렀을 때 효과가 여러 프레임 그려져도 작업 시작이 여러 번 발생한 것으로 읽지 않습니다.

| 단계 | 내용 |
| --- | --- |
| 입력 | app.py와 GUI 검사, 보존된 경우 pdf_panel.py |
| 처리 | 위젯 구성·이벤트·모션·대비의 변경 전 구현 읽기 |
| 출력 | 해당 화면 수정의 비교 기준 |

1. 자료 구성에서 실제 보존된 화면 코드를 엽니다.
2. 작업전 이름에 대응하는 위젯과 GUI 검사를 읽습니다.
3. 전체 비교에서 해당 화면의 변경 범위를 대조합니다.

<a id="level-1-section-7"></a>
### LEVEL 1 · 설치 환경과 실행·사용법

이 부분 본은 텍스트 편집기로 ButtonMotion과 기본 버튼의 입력 처리 코드를 읽는 데 사용합니다. 같은 시점 엔진·의존성·자산이 모두 있는 설치 묶음이 아니므로 누락 오류가 나도 설정을 임의로 바꾸어 완전 제품처럼 만들지 않습니다.

이 항목은 **부분 자료의 준비 조건**입니다. 남아 있는 UI/검사 외의 실행 자산과 엔진을 모두 보유했다는 뜻으로 읽지 않습니다.

Python 텍스트 편집기로 원문과 비교 자료를 엽니다. 변환 엔진·설치 의존성·자산의 완전한 같은 시점 묶음은 포함되지 않습니다.

관련 파일을 아래 링크에서 열어 순서대로 대조합니다.

<a id="level-1-section-8"></a>
### LEVEL 1 · app.py

설정 표의 VERSION 3은 `settings-3.ini`의 이름에 쓰이는 값이며 제품 3.0 을 뜻하지 않습니다.

DATA는 LOCALAPPDATA 아래 PUVKID/DragWheel 을 설정 기준으로 삼고 없으면 사용자 홈을 사용합니다.

TRIGGER_KEYS의 Shift·Alt·Ctrl·Windows·Space·F8은 원형 메뉴를 열 키 후보이고 custom의 -1은 직접 지정 키를 쓰는 표식입니다.

USER32는 창·키 상태 같은 Windows 기능, SHELL32는 탐색기에서 파일 위치를 찾는 기능, OLE32는 그 호출에서 얻은 메모리를 해제하는 기능과 연결됩니다. `WinDLL`은 Windows 기능을 불러오는 코드이며 사용자가 고르는 품질 설정이 아닙니다.

결과 위치를 선택하는 동작은 파일 자체 실행과 다릅니다.

- **select_in_explorer**: 파일을 실행하지 않고 탐색기에서 해당 파일을 선택한다. 예를 들어 기록에서 결과를 두 번 눌러 파일이 있는 위치를 찾는 동작입니다. [`select_in_explorer`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L68)
- **DialogTranslator**: 앱에서 사용하는 Qt 표준 대화상자의 짧은 문구만 현지화한다. 파일 선택창의 짧은 버튼 문구를 한국어로 읽더라도 선택한 파일 이름은 번역하지 않습니다. [`DialogTranslator`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L134)
- **file_urls**: 드롭에 포함된 모든 항목이 존재하는 로컬 파일/폴더인지 확인한다. 없는 파일이나 웹 주소를 파일 드롭으로 처리하지 않아야 합니다. [`file_urls`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L194)
- **HistoryList**: 결과 선택은 왼쪽 더블클릭으로만 실행한다. 기록의 결과를 고르는 조작과 결과 파일 자체를 실행하는 조작을 구분합니다. [`HistoryList`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L211)
- **ButtonMotion**: 입력 처리는 기본 버튼에 맡기고 배경·테두리만 부드럽게 그린다. 버튼이 반응해 보여도 눌러야 할 위치는 움직이지 않아야 합니다. [`ButtonMotion`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L221)
- **SoftTabs**: 페이지 위치와 입력 영역을 고정한 채 새 내용만 옅게 전환한다. 다른 탭으로 이동할 때 클릭 위치와 페이지의 실제 선택 의미는 유지합니다. [`SoftTabs`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L286)
- **MainWindow**: 상주 컨트롤러와 작은 설정창. 변환 선택은 원형 메뉴에서 수행한다. 메뉴·설정·현재 작업을 연결하는 창이며 실제 변환 엔진과 구분합니다. [`MainWindow`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L626)
- **append_record**: 두 변환 경로의 결과를 기존 기록 스키마로 저장한다. 성공·오류와 입력/결과의 대응을 남겨 나중에 찾도록 합니다. [`append_record`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L1106)

### LEVEL 1 · 처리 결과와 출력 읽기

여기서 얻는 결과는 ButtonMotion과 기본 버튼의 입력 처리의 변경 전 모습을 읽은 근거입니다. 새 PDF·OCR 문서가 생성되었다는 결과가 아닙니다. 버튼을 한 번 눌렀을 때 효과가 여러 프레임 그려져도 작업 시작이 여러 번 발생한 것으로 읽지 않습니다.

화면 소스의 이전 상태를 보여 주는 자료입니다. 변환·OCR 성공 결과나 완전한 설치 제품을 나타내지 않습니다.

## LEVEL 2 - Explorer · 구성과 처리 관계

[같은 수준 프로젝트](../읽기안내/레벨2.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨2.md) · [LEVEL 1 - Beginner](#reading-level-1) · [LEVEL 2 - Explorer](#reading-level-2) · [LEVEL 3 - Practitioner](#reading-level-3) · [LEVEL 4 - Advanced](#reading-level-4) · [LEVEL 5 - Expert](#reading-level-5) · [프로젝트 첫 화면](../../README.md)

`ButtonMotion`은 기본 버튼의 입력 처리를 유지하면서 배경과 테두리를 그립니다.

사용자의 누름이 버튼 동작으로 전달되는 경로와 시각 효과가 다시 그려지는 경로를 분리해 이해해야, 효과 변경이 클릭 횟수나 포커스를 바꾸지 않았는지 비교할 수 있습니다. `SoftTabs`는 페이지 위치와 입력 영역을 고정하고 내용 전환을 표현하는 별도 구성입니다.

GUI 검사 자료는 Qt 이벤트와 모션 상태를 확인하는 범위이며 탐색기 물리 입력 전체를 대신하지 않습니다. ‘작업전’이라는 이름은 보존 시점을 가리키며 버튼 모션 코드가 전혀 없었다는 뜻이 아닙니다.

### LEVEL 2 · 목적과 이 차수의 역할

app·GUI 검사만 남은 부분 기준본

| 3 | 확인된 직전 버전의 완전한 사본과 순서를 입증할 근거가 없어 이전 차수 비교를 만들지 않았습니다.<br>이후 버전 비교에 필요한 원문·해시는 위 목록에 보존했습니다. |

### LEVEL 2 · 입력·처리·출력

| 출력 | 해당 화면 수정의 비교 기준 |

버튼 위로 마우스 이동·누름·키보드 포커스이 어떤 상태를 바꾸고 어떤 표시로 돌아오는지 연결해 읽습니다. 사용자 조작과 모션 프레임을 같은 횟수로 세지 않으며 표시 완료와 실제 선택값을 구별합니다.

1. 자료 구성에서 실제 보존된 화면 코드를 엽니다.
2. 작업전 이름에 대응하는 위젯과 GUI 검사를 읽습니다.
3. 전체 비교에서 해당 화면의 변경 범위를 대조합니다.

<a id="level-2-section-7"></a>
### LEVEL 2 · 설치 환경과 실행·사용법

읽기 환경은 원문과 비교 자료를 볼 수 있으면 되지만, 버튼 위로 마우스 이동·누름·키보드 포커스을 실제 재현할 환경은 엔진·자산·의존성까지 별도로 필요합니다. 코드 열기와 앱 실행 준비를 같은 완료 상태로 묶지 않습니다.

이 항목은 **부분 자료의 준비 조건**입니다. 남아 있는 UI/검사 외의 실행 자산과 엔진을 모두 보유했다는 뜻으로 읽지 않습니다.

Python 텍스트 편집기로 원문과 비교 자료를 엽니다. 변환 엔진·설치 의존성·자산의 완전한 같은 시점 묶음은 포함되지 않습니다.

관련 파일을 아래 링크에서 열어 순서대로 대조합니다.

<a id="level-2-section-8"></a>
### LEVEL 2 · app.py

DATA와 VERSION으로 설정 파일 경로를 정하고 MainWindow가 트레이·설정·원형 메뉴를 연결합니다. 키 후보를 고른 값은 USER32로 읽는 실제 키 상태와 연결됩니다. 결과 위치 선택은 SHELL32가 경로를 해석하고 폴더 항목을 선택한 뒤 OLE32로 받은 메모리를 해제하는 흐름입니다.

DialogTranslator의 표준 문구 현지화와 사용자의 파일 명은 별개입니다. file_urls는 드롭 항목 모두가 존재하는 로컬 파일·폴더인지 확인하고, append_record는 결과를 기존 기록 형식에 연결합니다. 화면 효과의 변화가 이 입력·기록 의미를 바꾸는지 함께 읽습니다.

- [`select_in_explorer`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L68): 파일을 실행하지 않고 탐색기에서 해당 파일을 선택한다. 예를 들어 기록에서 결과를 두 번 눌러 파일이 있는 위치를 찾는 동작입니다.
- [`DialogTranslator`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L134): 앱에서 사용하는 Qt 표준 대화상자의 짧은 문구만 현지화한다. 파일 선택창의 짧은 버튼 문구를 한국어로 읽더라도 선택한 파일 이름은 번역하지 않습니다.
- [`file_urls`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L194): 드롭에 포함된 모든 항목이 존재하는 로컬 파일/폴더인지 확인한다. 없는 파일이나 웹 주소를 파일 드롭으로 처리하지 않아야 합니다.
- [`HistoryList`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L211): 결과 선택은 왼쪽 더블클릭으로만 실행한다. 기록의 결과를 고르는 조작과 결과 파일 자체를 실행하는 조작을 구분합니다.
- [`ButtonMotion`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L221): 입력 처리는 기본 버튼에 맡기고 배경·테두리만 부드럽게 그린다. 버튼이 반응해 보여도 눌러야 할 위치는 움직이지 않아야 합니다.
- [`SoftTabs`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L286): 페이지 위치와 입력 영역을 고정한 채 새 내용만 옅게 전환한다. 다른 탭으로 이동할 때 클릭 위치와 페이지의 실제 선택 의미는 유지합니다.
- [`MainWindow`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L626): 상주 컨트롤러와 작은 설정창. 변환 선택은 원형 메뉴에서 수행한다. 메뉴·설정·현재 작업을 연결하는 창이며 실제 변환 엔진과 구분합니다.
- [`append_record`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L1106): 두 변환 경로의 결과를 기존 기록 스키마로 저장한다. 성공·오류와 입력/결과의 대응을 남겨 나중에 찾도록 합니다.

### LEVEL 2 · 처리 결과와 출력 읽기

원문 비교는 배경·테두리 변화 중에도 클릭 위치와 실제 버튼 동작이 유지되는지 판단할 코드 근거를 제공하고, 실제 화면 관측은 별도 실행에서 얻습니다. 변환 엔진 결과와 이 부분 UI 자료의 결과를 같은 표에 합치지 않습니다.

화면 소스의 이전 상태를 보여 주는 자료입니다. 변환·OCR 성공 결과나 완전한 설치 제품을 나타내지 않습니다.

변경 전 app에서 ButtonMotion이 연결된 버튼을 확인하고, 변경 본에서 같은 버튼의 클릭 연결과 활성 조건을 대조합니다. 기본·호버·누름·키보드 포커스·비활성 상태를 구별하여 검수 항목을 세웁니다. 클릭 영역과 표시가 어긋나는지, 여러 번 눌렀을 때 작업이 중복 시작되는 지도 기능 검수 대상입니다.

이 보관본은 완전한 실행 자산을 포함하지 않습니다. 코드 대조 결과와 실제 화면 검수 결과를 별도로 작성하고, 실제 실행 없이 모션이 매끄럽다고 판정하지 않습니다.

### LEVEL 3 · 목적과 이 차수의 역할

app·GUI 검사만 남은 부분 기준본

| 2 | 실제 보존 파일의 공개 가능한 Python·고정 의존성·기존 라이선스만 바이트 그대로 수록했습니다.<br>실행 자산·개인 작업 기록·설치 바이너리는 이 사본에 포함하지 않습니다. |
| 3 | 확인된 직전 버전의 완전한 사본과 순서를 입증할 근거가 없어 이전 차수 비교를 만들지 않았습니다.<br>이후 버전 비교에 필요한 원문·해시는 위 목록에 보존했습니다. |

<a id="level-3-section-3"></a>
### LEVEL 3 · 입력·처리·출력

검토 입력으로 이 차수의 app·GUI 검사와 비교 대상 원문을 준비합니다. 배경·테두리 변화 중에도 클릭 위치와 실제 버튼 동작이 유지되는지 확인할 항목을 나누고 해당 코드 위치를 기록합니다. 실제 화면 관측이 없다면 출력 보고에는 코드 대조 결과로 표시합니다.

| 단계 | 내용 |
| --- | --- |
| 입력 | app.py와 GUI 검사, 보존된 경우 pdf_panel.py |
| 처리 | 위젯 구성·이벤트·모션·대비의 변경 전 구현 읽기 |
| 출력 | 해당 화면 수정의 비교 기준 |

<a id="level-3-section-4"></a>
### LEVEL 3 · 화면과 사용 흐름

검수 순서는 초기 상태 기록 → 버튼 위로 마우스 이동·누름·키보드 포커스 구분 → 최종 선택/표시 확인입니다. 배경·테두리 변화 중에도 클릭 위치와 실제 버튼 동작이 유지되는지 코드와 화면 증거를 나누어 판단합니다. 여기서는 장치를 조작하지 않았습니다.

1. 자료 구성에서 실제 보존된 화면 코드를 엽니다.
2. 작업전 이름에 대응하는 위젯과 GUI 검사를 읽습니다.
3. 전체 비교에서 해당 화면의 변경 범위를 대조합니다.

<a id="level-3-section-7"></a>
### LEVEL 3 · 설치 환경과 실행·사용법

먼저 파일목록의 UI·검사를 텍스트로 엽니다. 실제 실행이 필요하면 같은 시점의 누락 구성부터 확인하고, 준비되지 않은 상태에서는 배경·테두리 변화 중에도 클릭 위치와 실제 버튼 동작이 유지되는지 물리 검증 완료로 기록하지 않습니다.

이 항목은 **부분 자료의 준비 조건**입니다. 남아 있는 UI/검사 외의 실행 자산과 엔진을 모두 보유했다는 뜻으로 읽지 않습니다.

Python 텍스트 편집기로 원문과 비교 자료를 엽니다. 변환 엔진·설치 의존성·자산의 완전한 같은 시점 묶음은 포함되지 않습니다.

관련 파일을 아래 링크에서 열어 순서대로 대조합니다.

<a id="level-3-section-8"></a>
### LEVEL 3 · app.py

표의 VERSION을 제품 버전으로 적지 말고 실제 설정 파일 식별 값으로 확인합니다. 원형 메뉴 키는 표시 이름과 직접 지정 상태를 구분하고, 드롭에는 유효 파일·없는 파일·웹 주소를 나누어 검수합니다. 기록의 왼쪽 더블 클릭이 탐색기 선택으로 이어지는지와 파일 실행을 혼동하지 않습니다.

Windows DLL 이름을 제거하거나 다른 플랫폼용 이름으로 바꾸어 부분본을 강제로 실행하지 않습니다. 셸 선택 호출의 실패도 성공한 결과 선택으로 표시하지 않아야 합니다. 물리 탐색기·키 조작을 수행하지 않았다면 Qt 코드 검토와 구분해 기록합니다.

- [`select_in_explorer`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L68): 파일을 실행하지 않고 탐색기에서 해당 파일을 선택한다. 예를 들어 기록에서 결과를 두 번 눌러 파일이 있는 위치를 찾는 동작입니다.
- [`DialogTranslator`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L134): 앱에서 사용하는 Qt 표준 대화상자의 짧은 문구만 현지화한다. 파일 선택창의 짧은 버튼 문구를 한국어로 읽더라도 선택한 파일 이름은 번역하지 않습니다.
- [`file_urls`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L194): 드롭에 포함된 모든 항목이 존재하는 로컬 파일/폴더인지 확인한다. 없는 파일이나 웹 주소를 파일 드롭으로 처리하지 않아야 합니다.

- [`ButtonMotion`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L221): 입력 처리는 기본 버튼에 맡기고 배경·테두리만 부드럽게 그린다. 버튼이 반응해 보여도 눌러야 할 위치는 움직이지 않아야 합니다.
- [`SoftTabs`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L286): 페이지 위치와 입력 영역을 고정한 채 새 내용만 옅게 전환한다. 다른 탭으로 이동할 때 클릭 위치와 페이지의 실제 선택 의미는 유지합니다.
- [`MainWindow`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L626): 상주 컨트롤러와 작은 설정창. 변환 선택은 원형 메뉴에서 수행한다. 메뉴·설정·현재 작업을 연결하는 창이며 실제 변환 엔진과 구분합니다.

### LEVEL 3 · 처리 결과와 출력 읽기

확인한 코드 위치·차이·남은 미확인 동작을 기록합니다. 버튼 위로 마우스 이동·누름·키보드 포커스을 직접 실행했다면 그때의 환경과 화면 증거를 별도 덧붙이고, 실행하지 않았다면 성공 표시를 만들지 않습니다.

화면 소스의 이전 상태를 보여 주는 자료입니다. 변환·OCR 성공 결과나 완전한 설치 제품을 나타내지 않습니다.

## LEVEL 4 - Advanced · 구현 경계와 변경 영향

ButtonMotion의 표현 책임이 기본 버튼의 이벤트 처리 책임을 침범하지 않는지가 변경 경계입니다. 페인팅을 고치며 위젯 geometry나 입력 핸들러까지 바꾸면 단순 시각 수정의 범위를 넘습니다. SoftTabs와 함께 사용될 때 페이지 전환 중에도 버튼의 부모·입력 영역이 유지되는지 검토해야 합니다.

이 원문에는 ButtonMotion과 SoftTabs가 이미 존재하므로 이후 구성과 비교할 때 도입 여부와 수정 여부를 구별합니다. 부분 본에 없는 모듈을 삭제된 것으로 판정하거나 설치·배포 가능성을 추정하지 않습니다.

<a id="level-4-section-3"></a>
### LEVEL 4 · 입력·처리·출력

비교의 단위는 ButtonMotion과 기본 버튼의 입력 처리입니다. 원문 소스에서 확인되는 표현 책임과 입력 의미를 나누며, 완전한 실행 자산 부재로 확인하지 못한 동작을 별도 경계로 남깁니다. 이 자료의 산출물을 전체 엔진 호환성으로 확장하지 않습니다.

| 단계 | 내용 |
| --- | --- |
| 입력 | app.py와 GUI 검사, 보존된 경우 pdf_panel.py |
| 처리 | 위젯 구성·이벤트·모션·대비의 변경 전 구현 읽기 |
| 출력 | 해당 화면 수정의 비교 기준 |

<a id="level-4-section-4"></a>
### LEVEL 4 · 화면과 사용 흐름

ButtonMotion과 기본 버튼의 입력 처리 변경은 위젯의 입력 영역·현재 값·수명에 영향을 줄 수 있습니다. 빠른 후속 입력이나 창 닫기가 들어오는 경로를 포함하여, 표현 변경이 원래 조작 계약을 바꾸었는지 비교합니다.

1. 자료 구성에서 실제 보존된 화면 코드를 엽니다.
2. 작업전 이름에 대응하는 위젯과 GUI 검사를 읽습니다.
3. 전체 비교에서 해당 화면의 변경 범위를 대조합니다.

### LEVEL 4 · 설치 환경과 실행·사용법

동일 시점 실행 의존 집합이 없다는 한계 때문에 이 부분 본에서 확정할 수 있는 것은 코드 구조와 비교 범위입니다. ButtonMotion과 기본 버튼의 입력 처리의 실행 특성을 추정하기 위해 최신 엔진을 혼합하면 재현 조건이 달라집니다.

이 항목은 **부분 자료의 준비 조건**입니다. 남아 있는 UI/검사 외의 실행 자산과 엔진을 모두 보유했다는 뜻으로 읽지 않습니다.

Python 텍스트 편집기로 원문과 비교 자료를 엽니다. 변환 엔진·설치 의존성·자산의 완전한 같은 시점 묶음은 포함되지 않습니다.

### LEVEL 4 · app.py

Windows 셸에서 경로를 항목으로 해석한 뒤 선택하는 호출은 성공 코드와 할당된 메모리 수명을 함께 다룹니다. OLE32의 해제 책임을 빼면 단순 화면 문구 수정과 다른 자원 문제가 생깁니다. VERSION 변경 또한 QSettings 파일 경로를 바꾸므로 표시용 제품 버전 수정과 구별해야 합니다.

트리거 키·드롭 로컬 검증·기록 선택·번역은 서로 다른 입력/표시 경계입니다. 효과를 고치며 이 경계를 합치지 않고 기본 버튼·페이지 입력 의미와 연결해 비교합니다. 남은 함수 목록은 각 책임의 원문 링크이며 전체 기능을 같은 상투 문장으로 대신하지 않습니다.

- [`select_in_explorer`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L68): 파일을 실행하지 않고 탐색기에서 해당 파일을 선택한다. 예를 들어 기록에서 결과를 두 번 눌러 파일이 있는 위치를 찾는 동작입니다.
- [`DialogTranslator`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L134): 앱에서 사용하는 Qt 표준 대화상자의 짧은 문구만 현지화한다. 파일 선택창의 짧은 버튼 문구를 한국어로 읽더라도 선택한 파일 이름은 번역하지 않습니다.
- [`file_urls`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L194): 드롭에 포함된 모든 항목이 존재하는 로컬 파일/폴더인지 확인한다. 없는 파일이나 웹 주소를 파일 드롭으로 처리하지 않아야 합니다.
- [`HistoryList`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L211): 결과 선택은 왼쪽 더블클릭으로만 실행한다. 기록의 결과를 고르는 조작과 결과 파일 자체를 실행하는 조작을 구분합니다.
- [`ButtonMotion`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L221): 입력 처리는 기본 버튼에 맡기고 배경·테두리만 부드럽게 그린다. 버튼이 반응해 보여도 눌러야 할 위치는 움직이지 않아야 합니다.
- [`SoftTabs`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L286): 페이지 위치와 입력 영역을 고정한 채 새 내용만 옅게 전환한다. 다른 탭으로 이동할 때 클릭 위치와 페이지의 실제 선택 의미는 유지합니다.
- [`MainWindow`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L626): 상주 컨트롤러와 작은 설정창. 변환 선택은 원형 메뉴에서 수행한다. 메뉴·설정·현재 작업을 연결하는 창이며 실제 변환 엔진과 구분합니다.
- [`append_record`](../../history/%EB%B2%84%ED%8A%BC%EB%AA%A8%EC%85%98-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L1106): 두 변환 경로의 결과를 기존 기록 스키마로 저장한다. 성공·오류와 입력/결과의 대응을 남겨 나중에 찾도록 합니다.

### LEVEL 4 · 처리 결과와 출력 읽기

화면 소스의 이전 상태를 보여 주는 자료입니다. 변환·OCR 성공 결과나 완전한 설치 제품을 나타내지 않습니다.
