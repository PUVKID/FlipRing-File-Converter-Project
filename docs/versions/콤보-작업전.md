## LEVEL 1 - Beginner · 목적부터 결과 확인까지

[같은 수준 프로젝트](../읽기안내/레벨1.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨1.md) · [LEVEL 1 - Beginner](#reading-level-1) · [LEVEL 2 - Explorer](#reading-level-2) · [LEVEL 3 - Practitioner](#reading-level-3) · [LEVEL 4 - Advanced](#reading-level-4) · [LEVEL 5 - Expert](#reading-level-5) · [프로젝트 첫 화면](../../README.md)

콤보 상자는 눌러서 여러 항목 중 하나를 고르는 선택칸입니다. 예를 들어 출력 형식을 고른 뒤 화면을 스크롤하려고 휠을 굴렸는데 선택 형식까지 달라지면, 사용자는 다른 형식으로 변환할 수 있습니다. 이 자료는 그런 선택 조작을 다듬기 전 app·GUI 검사 기준입니다. **화면의 선택값과 실제 적용할 값이 같은지**가 읽을 핵심입니다.

마우스로 목록을 열어 고르는 동작, 키보드로 고르는 동작, 선택칸 위에서 휠을 굴리는 동작은 구별합니다. 이 설명은 검토할 상황이며 이 후보 작성에서 실제 장치 시험을 했다는 뜻은 아닙니다. 보존 파일목록에 없는 엔진이나 설치 파일은 포함된 것으로 보지 않습니다.

### LEVEL 1 · 입력·처리·출력

<a id="level-1-section-7"></a>
### LEVEL 1 · 설치 환경과 실행·사용법

이 부분본은 텍스트 편집기로 선택칸의 현재 값과 마우스·키보드·휠 이벤트 코드를 읽는 데 사용합니다. 같은 시점 엔진·의존성·자산이 모두 있는 설치 묶음이 아니므로 누락 오류가 나도 설정을 임의로 바꾸어 완전 제품처럼 만들지 않습니다.

이 항목은 **부분 자료의 준비 조건**입니다. 남아 있는 UI/검사 외의 실행 자산과 엔진을 모두 보유했다는 뜻으로 읽지 않습니다.

Python 텍스트 편집기로 원문과 비교 자료를 엽니다. 변환 엔진·설치 의존성·자산의 완전한 같은 시점 묶음은 포함되지 않습니다.

관련 파일을 아래 링크에서 열어 순서대로 대조합니다.

<a id="level-1-section-8"></a>
### LEVEL 1 · app.py

설정 표의 VERSION 3은 `settings-3.ini`의 이름에 쓰이는 값이며 제품 3.0을 뜻하지 않습니다. DATA는 LOCALAPPDATA 아래 PUVKID/DragWheel을 설정 기준으로 삼고 없으면 사용자 홈을 사용합니다. TRIGGER_KEYS의 Shift·Alt·Ctrl·Windows·Space·F8은 원형 메뉴를 열 키 후보이고 custom의 -1은 직접 지정 키를 쓰는 표식입니다.

USER32는 창·키 상태 같은 Windows 기능, SHELL32는 탐색기에서 파일 위치를 찾는 기능, OLE32는 그 호출에서 얻은 메모리를 해제하는 기능과 연결됩니다. `WinDLL`은 Windows 기능을 불러오는 코드이며 사용자가 고르는 품질 설정이 아닙니다. 결과 위치를 선택하는 동작은 파일 자체 실행과 다릅니다.

- **select_in_explorer**: 파일을 실행하지 않고 탐색기에서 해당 파일을 선택한다. 예를 들어 기록에서 결과를 두 번 눌러 파일이 있는 위치를 찾는 동작입니다. [`select_in_explorer`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L68)
- **DialogTranslator**: 앱에서 사용하는 Qt 표준 대화상자의 짧은 문구만 현지화한다. 파일 선택창의 짧은 버튼 문구를 한국어로 읽더라도 선택한 파일 이름은 번역하지 않습니다. [`DialogTranslator`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L134)
- **file_urls**: 드롭에 포함된 모든 항목이 존재하는 로컬 파일/폴더인지 확인한다. 없는 파일이나 웹 주소를 파일 드롭으로 처리하지 않아야 합니다. [`file_urls`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L195)
- **HistoryList**: 결과 선택은 왼쪽 더블클릭으로만 실행한다. 기록의 결과를 고르는 조작과 결과 파일 자체를 실행하는 조작을 구분합니다. [`HistoryList`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L212)
- **ButtonMotion**: 입력 처리는 기본 버튼에 맡기고 배경·테두리만 부드럽게 그린다. 버튼이 반응해 보여도 눌러야 할 위치는 움직이지 않아야 합니다. [`ButtonMotion`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L222)
- **install_button_motions**: 버튼이 모션을 직접 소유하게 하여 중복 등록과 전역 수명 보유를 막는다. 같은 버튼에 효과를 여러 번 연결하지 않는 것이 중요합니다. [`install_button_motions`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L290)
- **SoftTabs**: 페이지 위치와 입력 영역을 고정한 채 새 내용만 옅게 전환한다. 다른 탭으로 이동할 때 클릭 위치와 페이지의 실제 선택 의미는 유지합니다. [`SoftTabs`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L298)
- **MainWindow**: 상주 컨트롤러와 작은 설정창. 변환 선택은 원형 메뉴에서 수행한다. 메뉴·설정·현재 작업을 연결하는 창이며 실제 변환 엔진과 구분합니다. [`MainWindow`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L638)
- **append_record**: 두 변환 경로의 결과를 기존 기록 스키마로 저장한다. 성공·오류와 입력/결과의 대응을 남겨 나중에 찾도록 합니다. [`append_record`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L1117)

설정 이름은 코드에서 값을 구분하는 표식입니다. 아래 값은 당시 선언이며 바꾸라고 권하는 값이 아닙니다.

### LEVEL 1 · 처리 결과와 출력 읽기

여기서 얻는 결과는 선택칸의 현재 값과 마우스·키보드·휠 이벤트의 변경 전 모습을 읽은 근거입니다. 새 PDF·OCR 문서가 생성되었다는 결과가 아닙니다. 화면을 아래로 스크롤하려는 휠 조작과 출력 형식을 바꾸려는 선택 조작을 나누어 기록합니다.

화면 소스의 이전 상태를 보여 주는 자료입니다. 변환·OCR 성공 결과나 완전한 설치 제품을 나타내지 않습니다.

## LEVEL 2 - Explorer · 구성과 처리 관계

[같은 수준 프로젝트](../읽기안내/레벨2.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨2.md) · [LEVEL 1 - Beginner](#reading-level-1) · [LEVEL 2 - Explorer](#reading-level-2) · [LEVEL 3 - Practitioner](#reading-level-3) · [LEVEL 4 - Advanced](#reading-level-4) · [LEVEL 5 - Expert](#reading-level-5) · [프로젝트 첫 화면](../../README.md)

선택칸의 현재 값은 이후 작업 설정으로 전달됩니다. 따라서 팝업을 여는 표시만 바뀌어도 키보드 선택·휠 이벤트·포커스가 기본 Qt 동작과 어떤 관계인지 확인해야 합니다. app에 남은 버튼 모션과 탭 전환은 주변 표현이고, 콤보의 값 변경은 파일 처리 조건으로 연결되는 별도 의미입니다.

`install_button_motions`가 중복 효과 등록을 막는 역할과 콤보의 값 변경 정책을 혼동하지 않습니다. GUI 검사에서 조작을 모형화해 확인한 범위와 Windows 탐색기·물리 키 입력은 서로 다른 증거입니다.

### LEVEL 2 · 설치 환경과 실행·사용법

읽기 환경은 원문과 비교 자료를 볼 수 있으면 되지만, 목록에서 항목 선택·화살표 키·선택칸 위의 휠을 실제 재현할 환경은 엔진·자산·의존성까지 별도로 필요합니다. 코드 열기와 앱 실행 준비를 같은 완료 상태로 묶지 않습니다.

이 항목은 **부분 자료의 준비 조건**입니다. 남아 있는 UI/검사 외의 실행 자산과 엔진을 모두 보유했다는 뜻으로 읽지 않습니다.

Python 텍스트 편집기로 원문과 비교 자료를 엽니다. 변환 엔진·설치 의존성·자산의 완전한 같은 시점 묶음은 포함되지 않습니다.

관련 파일을 아래 링크에서 열어 순서대로 대조합니다.

<a id="level-2-section-8"></a>
### LEVEL 2 · app.py

DATA와 VERSION으로 설정 파일 경로를 정하고 MainWindow가 트레이·설정·원형 메뉴를 연결합니다. 키 후보를 고른 값은 USER32로 읽는 실제 키 상태와 연결됩니다. 결과 위치 선택은 SHELL32가 경로를 해석하고 폴더 항목을 선택한 뒤 OLE32로 받은 메모리를 해제하는 흐름입니다.

DialogTranslator의 표준 문구 현지화와 사용자의 파일명은 별개입니다. file_urls는 드롭 항목 모두가 존재하는 로컬 파일·폴더인지 확인하고, append_record는 결과를 기존 기록 형식에 연결합니다. 화면 효과의 변화가 이 입력·기록 의미를 바꾸는지 함께 읽습니다.

- [`select_in_explorer`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L68): 파일을 실행하지 않고 탐색기에서 해당 파일을 선택한다. 예를 들어 기록에서 결과를 두 번 눌러 파일이 있는 위치를 찾는 동작입니다.
- [`DialogTranslator`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L134): 앱에서 사용하는 Qt 표준 대화상자의 짧은 문구만 현지화한다. 파일 선택창의 짧은 버튼 문구를 한국어로 읽더라도 선택한 파일 이름은 번역하지 않습니다.
- [`file_urls`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L195): 드롭에 포함된 모든 항목이 존재하는 로컬 파일/폴더인지 확인한다. 없는 파일이나 웹 주소를 파일 드롭으로 처리하지 않아야 합니다.
- [`HistoryList`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L212): 결과 선택은 왼쪽 더블클릭으로만 실행한다. 기록의 결과를 고르는 조작과 결과 파일 자체를 실행하는 조작을 구분합니다.
- [`ButtonMotion`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L222): 입력 처리는 기본 버튼에 맡기고 배경·테두리만 부드럽게 그린다. 버튼이 반응해 보여도 눌러야 할 위치는 움직이지 않아야 합니다.
- [`install_button_motions`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L290): 버튼이 모션을 직접 소유하게 하여 중복 등록과 전역 수명 보유를 막는다. 같은 버튼에 효과를 여러 번 연결하지 않는 것이 중요합니다.
- [`SoftTabs`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L298): 페이지 위치와 입력 영역을 고정한 채 새 내용만 옅게 전환한다. 다른 탭으로 이동할 때 클릭 위치와 페이지의 실제 선택 의미는 유지합니다.
- [`MainWindow`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L638): 상주 컨트롤러와 작은 설정창. 변환 선택은 원형 메뉴에서 수행한다. 메뉴·설정·현재 작업을 연결하는 창이며 실제 변환 엔진과 구분합니다.
- [`append_record`](../../history/%EC%BD%A4%EB%B3%B4-%EC%9E%91%EC%97%85%EC%A0%84/app.py#L1117): 두 변환 경로의 결과를 기존 기록 스키마로 저장한다. 성공·오류와 입력/결과의 대응을 남겨 나중에 찾도록 합니다.

### LEVEL 2 · 처리 결과와 출력 읽기

원문 비교는 화면에 보이는 선택값과 실제 적용 값, 상위 스크롤 동작이 일치하는지 판단할 코드 근거를 제공하고, 실제 화면 관측은 별도 실행에서 얻습니다. 변환 엔진 결과와 이 부분 UI 자료의 결과를 같은 표에 합치지 않습니다.

화면 소스의 이전 상태를 보여 주는 자료입니다. 변환·OCR 성공 결과나 완전한 설치 제품을 나타내지 않습니다.

## LEVEL 3 - Practitioner · 준비·절차·오류 확인

[같은 수준 프로젝트](../읽기안내/레벨3.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨3.md) · [LEVEL 1 - Beginner](#reading-level-1) · [LEVEL 2 - Explorer](#reading-level-2) · [LEVEL 3 - Practitioner](#reading-level-3) · [LEVEL 4 - Advanced](#reading-level-4) · [LEVEL 5 - Expert](#reading-level-5) · [프로젝트 첫 화면](../../README.md)

비교할 선택칸의 초기 값과 최종 값을 기록합니다. 마우스로 선택, 화살표 키 선택, 팝업 열린 상태의 휠, 닫힌 상태의 휠을 각각 나누어 확인할 항목을 만듭니다. 출력 형식처럼 작업 결과에 영향을 주는 값은 표시 문구와 내부 데이터가 일치하는지도 대조합니다.

변경 전·후 app과 test_gui에서 이벤트 처리와 기대 상태를 함께 읽습니다. 부분본만으로 전체 앱을 실행한 것으로 보고하지 않으며, 실제 조작 검수는 별도 실행 환경과 결과를 확보한 경우에만 기록합니다.
