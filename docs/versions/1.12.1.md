# 1.12.1 · 문서 입력과 프리셋 간격 보완

**ABW·DIF 입력을 보완하고 프리셋의 빈 간격을 줄였습니다.** 공개 실행 파일과 설치 파일은 준비 중입니다.

[LEVEL 1 - Beginner](#reading-level-1) · [LEVEL 2 - Explorer](#reading-level-2) · [LEVEL 3 - Practitioner](#reading-level-3) · [LEVEL 4 - Advanced](#reading-level-4) · [LEVEL 5 - Expert](#reading-level-5) · [프로젝트 첫 화면](../../README.md)

| 변경 | 동작 |
|---|---|
| **ABW** | 정해진 DTD 선언만 격리 사본에서 제거하고 다른 DTD·엔터티는 거부 |
| **DIF** | 원본을 보존하고 필요 시 UTF-8 사본과 전용 필터 사용 |
| **프리셋** | 펼친 영역의 높이 조정, 한글·영문 간격 확인 |
| 검사·빌드 | 문서 입력 검사 추가, 화면 계약 및 버전 정보 갱신 |

<a id="reading-level-1"></a>
## LEVEL 1 - Beginner · 문서 변환을 시작하는 방법

[같은 수준 프로젝트](../읽기안내/레벨1.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨1.md) · [같은 수준 이전 차수](1.12.0.md#reading-level-1)

ABW는 AbiWord 문서이고 DIF는 표를 옮기는 파일 형식입니다. 파일을 선택해 원하는 출력 형식을 고르고 변환합니다. 원본은 그대로 두고 필요한 경우 임시 사본을 사용합니다. 변환 뒤 글자와 표가 원하는 대로 보이는지 확인하세요.

<a id="reading-level-2"></a>
## LEVEL 2 - Explorer · 입력과 안전한 사본

[같은 수준 프로젝트](../읽기안내/레벨2.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨2.md) · [같은 수준 이전 차수](1.12.0.md#reading-level-2)

ABW의 정해진 DTD 선언만 안전 사본에서 제거하고 나머지 DTD와 엔터티는 거부합니다. DIF는 문자 인코딩을 순서대로 해석해 UTF-8 사본을 만듭니다. 파일 이름이 충돌하면 기존 파일을 덮어쓰지 않습니다.

<a id="reading-level-3"></a>
## LEVEL 3 - Practitioner · 사용과 오류 확인

[같은 수준 프로젝트](../읽기안내/레벨3.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨3.md) · [같은 수준 이전 차수](1.12.0.md#reading-level-3)

문서 변환에는 형식에 따라 LibreOffice 등 외부 도구가 필요합니다. ABW 또는 DIF를 선택하고 출력 형식을 지정한 후 결과를 확인하세요. 지원하지 않는 DTD, 잘못된 문자 바이트, 사본 이름 충돌은 오류로 처리합니다. DIF의 문자셋 식별이 없는 경우 자동 판별의 한계가 있습니다.

<a id="reading-level-4"></a>
## LEVEL 4 - Advanced · 구현 경계와 조건

[같은 수준 프로젝트](../읽기안내/레벨4.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨4.md) · [같은 수준 이전 차수](1.12.0.md#reading-level-4)

document_formats는 Expat으로 인코딩과 무관하게 DTD·엔터티를 검사하고 정확한 AbiWord 정형 선언만 격리 사본에서 제거합니다. DIF는 BOM UTF-16, UTF-8-sig, CP949, CP1252 순으로 해석하고 필요할 때 배타적으로 UTF-8 사본을 만듭니다. document_bridge는 DIF 필터에 UTF-8 문자집합 옵션 76을 지정합니다.

<a id="reading-level-5"></a>
## LEVEL 5 - Expert · 검사와 남은 한계

[같은 수준 프로젝트](../읽기안내/레벨5.md) · [같은 수준 프로필](https://github.com/PUVKID/PUVKID/blob/main/docs/읽기안내/레벨5.md) · [같은 수준 이전 차수](1.12.0.md#reading-level-5)

서로 다른 기존 전체 기능 검사 377개가 통과했고 그중 104개는 현행 화면 계약 보완 결과입니다. 문서 입력 신규 단위 검사 6개, 실제 템플릿 12개와 DIF UTF-8·CP949 한글 셀을 확인했습니다. 템플릿 4개 최초 실패는 입력 생성에서 XML 네임스페이스 표기가 바뀐 원인이었고 원문 속성만 치환한 후 통과했습니다. BOM UTF-16은 단위 검사로 확인했습니다.

## 확인 범위와 제한

| 확인 | 관측과 한계 |
|---|---|
| 프리셋 | 한글·영문 제목과 입력 사이 간격 7픽셀 |
| 문서 | iWork 구형·신형 대표 본문과 셀, HWP·HWPX 출력의 별도 LibreOffice/H2Orestart 재열기에서 한글·표·그림 확인 |
| 검증 대기 | 새 실행·설치 파일, 실제 탐색기 Shift/OLE, 새 외부 도구 설치·UAC, 한컴 화면의 시각 정합 |

OS 테마 변경과 설치 동작의 모형 검사는 실제 운영체제 동작을 대신하지 않습니다. 모든 서식의 동일성과 모든 입력·환경의 무결함을 보장하지 않습니다. 기존 오류와 후속 확인을 구분합니다.
