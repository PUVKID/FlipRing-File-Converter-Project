# 최종·같은 1.11.0의 납품 구성

> 11월 14일의 검사 기록은 당시 상태로 보존했습니다. 이후 확인한 제품과 납품 상태는 [2026년 11월 20일 확인 범위](#product-verification-20261120)에서 구분합니다.

## 2026-11-14 보완 · 새 배포의 검증 사실

위 LEVEL 5는 보존 시점의 원문입니다. 위에 남은 ‘갱신 대기’ 또는 이전 납품 크기·해시는 당시 기록이며 아래 새 파일과 합치지 않습니다. 이 절은 보존 원문 밖에서 현재 확인 사실을 추가합니다.

빌드 종료 코드 0·173.625초, 실행 폴더 1,207 파일·478,350,675바이트를 확인했습니다.

ZIP은 948 항목입니다.

실행 폴더와 설치 본의 동일 파일 1,207개가 맞으며 제거기 2개가 추가됩니다.

단독·설치 EXE에서 각각 HWP/HWPX 두 출력을 만들어 고정 검사 한 개씩 통과했습니다.

한글·표·서식·PNG 원 바이트를 확인했으며 외부 한글 뷰어의 시각 검증은 아닙니다.

라이선스 JSON의 최초 바이트 불일치 실패를 보존하고, 항목 객체의 동등성을 확인한 뒤 정렬·EOF만 4,504 →4,502 바이트로 맞췄습니다.

나머지 951개 동 결 메타데이터는 같았고, 후속 ZIP 기준 대조 차이는 0입니다.

독립 검토 5,593 조건 PASS는 새 빌드나 설치를 다시 실행한 결과가 아닙니다.

내장 코드 21개, 현재 Python 48개·도구 6개, native 자료와 실제 설치 파일을 직접 대조한 범위를 뜻합니다.

기존 51·163·86 및 독립 35 검사 이력은 이번 재실행 수와 구분합니다.

사용자가 Shift PNG·문서 저장·원본 보존·중앙 취소를 확인했고, 실제 파일과 성공 기록 두 건은 PNG와 **HWP**였습니다.

원본 두 파일 SHA가 그대로이며 JPG/PNG RGB 및 HWP 한글·표·그림 대조가 통과했습니다.

HWPX 사용자 물리 시험은 별도 확인 대기입니다.

최종 폴더 교체·Git 커밋/푸시·새 원격 파일 대조·중앙 완료 검사는 이 후보 시점에 미완료입니다.
