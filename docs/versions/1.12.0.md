# 1.12.0 · 빠른 작업과 라이트·다크 테마



구현·빌드·설치를 마쳤습니다. 저장한 작업을 원형 메뉴와 대기열에서 실행하고, 폴더 변환·전후 비교·목표 용량·결과 정리를 한 흐름으로 연결했습니다.



[LEVEL 1 - Beginner](#reading-level-1) · [LEVEL 2 - Explorer](#reading-level-2) · [LEVEL 3 - Practitioner](#reading-level-3) · [LEVEL 4 - Advanced](#reading-level-4) · [LEVEL 5 - Expert](#reading-level-5) · [프로젝트 첫 화면](../../README.md)



| 주요 변경 | 동작 |
|---|---|
| 빠른 작업 | 설정 저장·이름 변경·가져오기·내보내기·원형 메뉴 바로 실행 |
| 파일과 폴더 | 하위 구조·필터·중복 제거·원본 보존·이름 충돌 회피 |
| 대기열과 결과 | 순서·정지·취소·실패 재시도·비교·보관 정리·되돌리기 |
| 화면과 도구 | 라이트·다크·시스템 저장·내부 선택창 통일·앱에서 도구 설치 |
