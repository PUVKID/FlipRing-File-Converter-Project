# 플립링 1.15.0 · 간단한 화면과 실제 결과 미리보기

파일을 선택하고 결과를 확인한 뒤 변환하는 흐름으로 화면을 정리했습니다. 기존 기능을 삭제하지 않고 자주 쓰는 네 메뉴와 ‘더 보기’로 나눴습니다.

| 영역 | 바뀐 동작 | 보존한 기능 |
|---|---|---|
| 기본 화면 | 파일 선택·출력 형식·미리보기·실행 순서로 정렬 | 탐색기 Shift 드래그·원형 메뉴·원본 보존 |
| 내부 화면 | 설명 중복·장식·고정 큰 빈칸을 줄이고 부가 옵션 접기 | PDF·OCR·작업 공간·빠른 작업·기록·도구 |
| 실제 미리보기 | 임시 복사본을 같은 변환 엔진으로 처리하고 실제 바이트 표시 | 원본과 기존 출력은 변경하지 않음 |
| 오류 해결 | 짧은 원인과 해당 해결 버튼, 기술 상세는 접기 | 허용한 외부 도구의 기존 설치 흐름 |
| 테마·입력 | 라이트·다크·시스템과 한국어·영어 유지 | 나눔고딕700·모션 줄이기·고정 창과 작은 화면 스크롤 |

## 사용과 조건

| 순서 | 조작 | 확인할 결과 |
|---|---|---|
| 1 | 파일을 선택하고 출력 형식을 고르기 | 앱 안 선택은 자동 원형 메뉴를 띄우지 않음 |
| 2 | ‘결과 미리보기’ 선택 | 새 임시 결과의 그림 또는 문서 표시·실제 용량·손실 안내 |
| 3 | 닫고 ‘변환 실행’ 선택 | 정상 결과는 별도로 저장하며 원본 유지 |
| 4 | 실패하면 해결 버튼 선택 | 설치·다른 파일 선택·형식 변경·다시 시도 중 해당 동작 |

미리보기는 **파일 한 개·128MiB 이하**입니다. 폴더는 받지 않습니다. 60초가 지나면 취소를 요청하며 작업 스레드가 끝날 때까지 임시 파일을 보존합니다. 이미지·PDF 등 렌더러가 있는 결과는 화면으로 보며, 나머지는 실제 결과의 종류·용량을 표시합니다. 여러 파일을 출력하는 변환은 전체 용량과 첫 표시 가능한 이미지를 안내합니다. 모든 형식을 같은 방식으로 시각화한다는 뜻은 아닙니다.

JPG 손실 압축·투명도, 애니메이션 프레임, 문서 배치·글꼴, CSV의 수식·서식·여러 시트, 일부 미디어 트랙·메타데이터 손실을 경고합니다. 원본 파일명이 FFmpeg와 같다는 이유만으로 설치 버튼을 보여 주지 않습니다. Python DLL 충돌은 구성 점검으로 안내합니다. 미리보기 실패에서도 해당 해결 버튼을 제공합니다.

## 검사와 배포

| 근거 | 실제 확인 범위 | 한계 |
|---|---|---|
| 코어·Qt 검사 | 실제 이미지 변환·바이트·원본·정리·취소, 분류·버튼 연결, 두 테마·한영·메뉴 | 제어된 입력과 Qt 환경 |
| 독립 검토 | 파일명 오탐·실제 GIF 2→1프레임 경고·실패 버튼 연결 및 수명 | 전수 미래 입력 보증이 아님 |
| 배치 검사 | 파일 선택 버튼 경계와 오류 카드 높이, 20개 오프스크린 화면 | 물리 Windows 입력과 구분 |
| 실행·설치 | [이번 배포 확인](../1.15.0_배포확인.md) | 실제 수행한 항목만 별도 기록 |

기존 HWP5 저장의 실험적 범위와 복잡한 문서의 제한은 유지합니다. 새 설치본의 물리 Explorer Shift/OLE는 기존 검사와 구분하며 이번 차수에서 수행하지 않았다면 통과로 적지 않습니다. [사용 안내](../1.15-사용안내.md) · [전체 소스 비교](../revision-audit/1.15.0.md)
