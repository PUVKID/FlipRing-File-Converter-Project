# 플립링 1.9.0 · 연속 수정

파일을 모아 처리 순서를 조합하고, 원본을 보존한 결과를 만드는 Windows 앱입니다. 무료 배포이며 제작자는 PUVKID입니다. 기존 버전과 보존본은 유지합니다.

## 추가한 기능

- Ctrl+K 명령 검색, 이름 규칙에 따른 복사본 생성, 기록 검색·필터·복사·탐색기 선택.
- 카드 조합, 목표 형식·용량·A4·품질·해상도, 순서가 있는 레시피 저장·가져오기·내보내기·실행.
- 사용자가 켠 감시 폴더의 안정된 파일 처리, 결과·임시 파일·재처리 루프 제외, 휠 순서·숨김·레시피 호출.
- 클립보드 이미지·텍스트, 사용자가 시작한 영역 캡처, 결과 파일 드래그.
- PDF·이미지 동기 비교, 실제 인식 위치·확신도와 OCR 텍스트 교정, TXT·PDF·DOCX·XLSX 저장.
- PDF 합치기·이미지 PDF·콜라주·GIF·문자와 이미지 워터마크·영수증 OCR 표.
- 흐림·가장자리·빈/중복 페이지·개인정보 후보 검토와 사용자가 확인한 영역의 실제 픽셀 가림.

개인정보·흐림 등의 후보는 검토 보조이며 완전 탐지 보장이 없습니다. 가림은 사용자가 확인한 영역에만 적용합니다. OCR과 표 열 복원은 문서에 따라 달라집니다. 달성 불가능한 압축 목표를 성공으로 표시하지 않습니다. 지원하지 않는 입력·조합은 오류로 알립니다.

## 화면과 모션

흑백·회색과 SUIT 글꼴, 1160×820 논리 크기를 유지합니다. 화면이 작으면 작업 영역을 스크롤합니다. 파일·폴더 선택창, PDF·OCR, 팝업과 설정의 표면·간격·포커스를 통일했습니다. 한국어·영어와 모션 축소를 제공합니다. 파일 카드·단계·완료 모션은 실제 처리 상태와 연결되며 정지 이미지를 작업 화면처럼 사용하지 않습니다.

Qt 가상 화면 100·125·150·200%와 640×480 조건에서 한영 7개 탭·팝업 등 160개 PNG를 생성하고 대표 9개를 직접 검토했습니다. 실제 운영체제 배율 변경이나 모든 모니터 전환을 검증했다는 뜻은 아닙니다.

## 실제 검증 범위

- 기존 회귀 **163개**, 확장 검사 **86개**, 총 **249개**를 실제 ID와 대조해 통과했습니다. 누락·중복·건너뜀은 없습니다. 각 묶음 실행은 42.125초와 20.484초입니다.
- Windows에서 새 실행 파일과 설치 파일을 빌드하고, 설치 종료 코드 0 및 제품 626파일의 크기·SHA-256 일치를 확인했습니다.
- 빌드에 포함된 제품 모듈 16개를 현재 소스의 재귀 코드 객체와 대조했습니다. 실제 설치한 EXE의 프로세스 기동·창 생성도 확인했습니다.
- OCR 시작 전 Job 연결과 시작·취소·시한·실패 정리를 검사했습니다. 검사 대기는 실제 이벤트 루프와 같은 방식으로 관찰하며 27초 제한을 유지합니다. 예전 실패 기록을 성공으로 덮지 않습니다.
- 새 1.9 설치본의 탐색기 Shift 드래그·PNG 생성·JPG 원본 보존·중앙 취소를 사용자가 직접 시험하여 모두 정상임을 확인했습니다. 도구로 원본 SHA-256 불변과 실제 PNG(960×600) 형식·크기·디코딩 RGB 일치를 추가 대조했습니다. 이는 해당 시험 표본의 확인이며 모든 파일 형식의 물리 입력 전수 검사는 아닙니다.
- 네이티브 화면의 마우스·키보드 자동 조작 도구가 이 세션에 노출되지 않아 실제 선택창 입력·모니터 전환·체감 모션 확인에는 이 제한이 있습니다.

## 파일 구성과 빌드

- 실행: `프로그램/FlipRing/FlipRing.exe`
- 설치: `설치파일/FlipRing-Setup.exe`
- 전체 소스·자산·라이선스·고정 의존성과 빌드 안내: `소스/`, `소스/빌드방법.md`
- 전체 검사 하네스: `검사도구/`
- 배포 파일 크기·SHA-256: `SHA256SUMS.txt`

새 설치·설정·실행 잠금과 자동 시작 이름은 FlipRing19로 분리했습니다. 바탕화면·시작 메뉴 바로가기, 정션, 심볼릭 링크를 만들지 않습니다. 포함 라이브러리의 원문 라이선스와 필요한 상응 소스는 로컬 전체 납품에 보존합니다. 대용량 실행 파일·라이브러리·모델을 Git 본문에 중복 업로드하지 않으며 공개 저장소의 소스 범위와 로컬 납품 범위를 구분합니다.

| 파일 | 바이트 | SHA-256 |
|---|---:|---|
| 프로그램/FlipRing/FlipRing.exe | 7194137 | `0f0545cb3c3b069bcc29b8cfa0a90de7a800d965dfbdb078a6396ad304865892` |
| 설치파일/FlipRing-Setup.exe | 563308489 | `217b998441e9a8208a55e554107e4f93ac0bf505cd5992fb10663e5813d5815d` |

라이선스 조사 도구의 운영 보고 항목만 제거한 자료로 설치 파일을 다시 패키징했습니다. 상응 소스·저작권 고지와 제품 EXE는 그대로 보존했습니다. 새 설치는 종료0·12.093초였고 제품626파일의 크기·SHA-256을 다시 대조했습니다. 새 설치 경로의 실제 실행에서 4초 이상 생존·설정 창·응답 상태를 확인했습니다. 동일 EXE의 사용자 Shift 시험 결과는 앞의 확인에 해당하며 이번 자료 정리 후 물리 입력을 다시 시험했다고 주장하지 않습니다.

이번 결과는 기존1.8.0을 잇는1.9.0 연속 수정본입니다. 현재 버전 폴더로 이동한 뒤 동일 설치기를 실제 설치5에서 다시 실행해 종료0·8.640초를 확인했습니다. 제품626파일 전체의 크기·SHA-256이 일치했고 새 설치 경로의 앱이4초 이상 생존하며 설정 창과 응답 상태가 정상임을 확인했습니다. EXE와 설치기 바이트는 이동 전과 같으며 기존16모듈 코드 대조는 같은 EXE 해시에 재결합했습니다. 과거 설치 보고서의 당시 경로는 원문 그대로 보존합니다.
