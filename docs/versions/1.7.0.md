# 1.7.0

이번 작업 흐름 확장 소스. 설치·실제 조작 결과는 별도 검증 기록으로 구분

## 코드·화면·설정·검사의 확인 범위

1.6 대비 app.py에 파일별 큐, flipring_workflow.py에 프리셋·사전 점검, preview_panel.py에 실제 이미지 비교, pdf_pages.py에 페이지 편집 모델, pdf_lock.py에 공용 PDFium 잠금을 추가했습니다. app.py는 전용 설정·큐·프리셋·미리보기와 모션 감소를 연결하며 pdf_panel.py는 썸네일 순서·선택·회전·삭제·추출·확대·저장을 제공합니다. engine.py는 짧은 독립 LibreOffice 프로필과 동봉 7-Zip RAR 처리·취소 회수를 포함합니다. build.py는 1.7.0과 별도 출력 경로를 사용하고 package.py는 새 코드·자산·7-Zip 고지와 상응 소스의 크기·해시를 검증합니다. test_workbench.py·test_pdf_workspace.py·test_conversion_matrix.py가 추가되며 기존 PDF 검사 원문은 변경하지 않았습니다. 화면·설정·실패 경로·검사의 세부 파일 차이와 공백·주석은 아래 전체 패치에 포함됩니다.

실제 보존 파일의 공개 가능한 Python·고정 의존성·기존 라이선스만 바이트 그대로 수록했습니다. 실행 자산·개인 작업 기록·설치 바이너리는 이 사본에 포함하지 않습니다.

[소스 폴더](../../history/1.7.0/) · [크기·SHA-256 목록](../../history/1.7.0/파일목록.json)

원래 1차·2차와 이 자료의 대응 번호는 입증되지 않아 임의로 붙이지 않았습니다. 부분 기준본의 누락 파일은 제품에서 삭제됐다는 뜻이 아닙니다.

비교 대상: [1.6.0](1.6.0.md). 확인 가능한 앞선 보존 버전과의 비교이며, 중간 버전 전체가 존재한다는 뜻은 아닙니다.

## 2026-10-30 검증 결과와 제한

- 독립 소스 검사: GUI85·기존 PDF/OCR28·일반 작업20·신규 PDF 편집30, 합계163개 통과. 격리 실행24.484초이며 기존 제한을 유지했습니다. 앞선 중복 부하에서는 시간 초과가 있었고 그 이력을 보존했습니다.
- 실제 변환표: 266개 조합과 추가 안전 검사3개 통과. 누락·중복·도우미 부재·입력 자료 부재0. 한정된 생성 자료와 지정된 외부 도구로 실행한 결과이며 모든 사용자 문서의 정확도를 보장하지 않습니다.
- 배포 대조: 새 실행 파일의 주요 모듈11개가 소스와 일치. 실제 설치 종료0, 설치된624파일이 배포본과 일치. Windows의 응답하는 새 앱 창을 확인했습니다.
- 새 설치본의 실제 Shift/OLE 드래그·PNG 생성·원본 보존·중앙 취소와 PDF 페이지 이동·새 저장을 사용자가 정상 확인했습니다. 실제 PNG 파일·픽셀과 원본 해시는 별도 대조했습니다. Qt 오프스크린 검사와 사용자 실제 조작 확인의 범위를 구분합니다.
- 후속 부모 반복 검사에서는 모션 종료 검사78의 간헐 실패가 재현됐습니다. 최초 독립163개 통과 기록과 반복 실패를 함께 보존하며, 후속1.8에서 원인 계측·수정·재검증을 진행합니다. [이번 확인과 실제 문서 변경 기록](../changes/2026-10-30_1.7_실제조작확인.md)을 참고하세요.
- OCR 배치·복잡한 표·수식의 완전 복원과 PDF 압축률은 보장하지 않습니다. FFmpeg·Pandoc·LibreOffice는 필요한 작업에 별도 설치가 필요합니다.
- [이전·현재 실행/설치 파일 크기와 SHA-256](배포파일-크기와해시.json). 바이너리 내부 내용과 성능은 크기·해시만으로 추정하지 않습니다.
