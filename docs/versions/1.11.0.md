| 전체 자동 조작과 구분 | 모든 버튼과 화면을 자동으로 시험했다는 뜻은 아닙니다. |

| 회귀 검사의 뜻 | 회귀 검사는 변경 뒤 기존 동작이 유지되는지 확인하는 검사입니다. |
| HEIC 표본·일반화 한계 | 자체 HEIC 시험 자료도 포함하지만 모든 외부 사진의 변환 품질을 보증하지 않습니다. |
| 외부 변환 도구 의존 | Office 변환은 LibreOffice가 따로 필요하고, 일부 영상·오디오·문서에는 FFmpeg 또는 Pandoc이 필요합니다. |
| 복잡한 배치 확인 | 복잡한 글꼴·수식·페이지 배치는 변환 뒤 열어 확인하세요. |
| 당시 읽기·저장 지원 범위 | 당시 배포에서는 HWP/HWPX 읽기·다른 형식 변환을 다루며 저장은 지원하지 않았고, 초기 Excel 2007 Beta2 XLSB도 지원하지 않았습니다. |
| 후속 저장 코어·배포 상태 | 이후 HWP 저장 코어를 제한적으로 구현·검사했지만 이전 후보 작성 당시에는 새 빌드와 실제 설치본 조작 확인이 미완료였습니다. |

| 표본·해시·픽셀 근거 | 생성 PNG·기록·원본 SHA·픽셀 비교는 해당 입력과 동작의 근거입니다. |
| 실행·소스 묶음 용도 | 프로그램과 설치 파일은 실행용, 전체 소스 ZIP은 구현과 상응 소스 추적용입니다. |
| 묶음 크기·해시 구분 | 크기·SHA 표는 이 셋을 정확히 구별합니다. |
| 상응 소스 해시 범위 | 10개 상응 소스의 개별 해시는 동봉 라이브러리 원문과 연결되며 실행 파일 해시와 바꿔 쓰지 않습니다. |
| 후속 구현·기존 배포 계보 | 후속 HWP 저장 구현 검사는 이 보존 배포의 해시를 바꾸지 않으며 당시 새 배포 연결은 미완료였습니다. |
