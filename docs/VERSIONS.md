## 📏 기존 수량표를 읽는 방법

아래 표는 기존 공개 원본 집계입니다. 이번에 추가한 차수 해설과 `assets/overview.png`는 연구 원본 수량에 더하지 않습니다. 상위 포장 폴더가 바뀌면 추가·이전 경로가 크게 늘 수 있으므로 기능 변화는 위 해설과 함께 읽어 주세요.

# 현재 공개 파일과 차수별 변화

| 차수·위치 | 현재 파일 | 추가 경로 | 내용 변경 | 이전에만 존재 |
|---|---:|---:|---:|---:|
| `기본` | 99 | 99 | 0 | 0 |

- 현재 연구 파일 합계: **99개**. 루트 `README.md`, `CHANGELOG.md`, `.gitignore`와 `docs/` 관리 문서는 집계에서 제외합니다.
- 경로에서 처음 만나는 숫자 차수 또는 `최종`으로 묶습니다. 같은 상위 경로의 숫자 차수끼리만 경로·SHA-256을 비교합니다. `기본`과 `최종`은 독립 묶음이므로 다른 차수와 자동으로 의미 대응시키지 않습니다.
- 추가·변경·이전 경로 수는 파일 비교 결과입니다. 기능 변경은 [README의 구체적인 구현·차수 설명](../README.md)을 함께 확인하세요.
- 제외된 원데이터·모델·인증정보와 관리 문서는 이 표의 대상이 아닙니다.
