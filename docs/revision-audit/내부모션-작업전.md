BOM의 표시 차이와 인코딩 변환은 바이트 해시·별도 원문 해시 기록으로 구분하며 JSON 해시는 실제 공개 사본의 바이트 기준입니다. 공백·주석을 무시하는 옵션은 사용하지 않았고, 바이너리 내용은 추정하지 않았습니다. 이전 소스·빌드 실행·실기기 검증을 이번에 재수행한 결과가 아닙니다.
