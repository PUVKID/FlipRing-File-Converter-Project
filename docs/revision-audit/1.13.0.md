# 1.13.0 · 초기 공개 소스 동기화 후보 기록

**초기 후보의 기록입니다.** 현재 공개 소스는 [최종 동기화 비교](1.13.0-최종동기화.md)를 확인하세요.

이 목록과 74개 조각은 기존 공개 소스에서 첫 후보로 준비한 300개 경로의 비교입니다. 당시 문서 분류는 고객 문서 7개였으며, 최종 빌드는 6개와 과거 보완 문서의 개별 제외로 바뀌었습니다. 현재 파일이나 최종 배포 구성을 나타내는 목록으로 사용하지 마세요. 실제 1.12.1 대비 변경은 [직전 비교](1.13.0-직전비교.md)에서 구분합니다.
