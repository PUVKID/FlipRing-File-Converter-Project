# 공개 사본의 개인 표시·경로 정리

이번 공개 사본은 개인 프로필 계정 표시와 개인 사용자 경로를 정리했습니다. 자기 이메일, 논문 저자, 저작권·라이선스의 권리자, 필수 저장소 URL은 유지합니다. 설정 폴더·설치 ID·패키지명·고정 시험 입력처럼 제품 호환과 검사 의미에 필요한 식별자는 표시명과 구분해 유지합니다.

개인 경로가 실행 입력·삭제/이동 가드인 과거 일회성 도구와 직접 의존 보조 도구는 원문을 비공개로 보존하고 공개 안내로 연결합니다. 현재 제품 런타임과 가드를 임의로 바꾸지 않았습니다. 일반 프로젝트 D드라이브 경로가 실제 실행 계약인 소스도 보존합니다.

차수 비교는 정리된 양쪽 공개 사본끼리 다시 생성했습니다. 원래 개인 값은 삭제 줄에 싣지 않습니다. 파일별 크기·해시는 현재 공개 바이트이며, 보존기준·배포 SHA 목록·원본 대응 해시는 과거 원문 기준과 구분합니다. 과거 빌드·실기기·성능 검증을 이번에 다시 실행한 것으로 해석하지 마세요. 이번 변경은 개인정보 정리이며 제품 기능 개선이나 원본 재검증 결과가 아닙니다.
