설치 파일·프로그램 폴더·전체 소스와 빌드 방법을 함께 제공합니다. 설치본 실행은 Python/Rust 개발 환경을 요구하지 않습니다. 공개 Git 선택 소스와 도우미·상응 소스를 포함한 전체 소스 ZIP은 범위가 다릅니다. [릴리스](https://github.com/PUVKID/FlipRing-File-Converter-Project/releases/tag/v1.15.0) · [빌드 방법](../history/1.15.0/소스/빌드방법.md)

미리보기는 128MiB 이하 파일 한 개, 60초 후 취소 요청이며 실제 작업 종료를 기다립니다. 표시 가능한 이미지·PDF는 시각화하고 나머지 형식은 실제 결과 정보로 안내합니다. HWP5 저장은 실험적이며 OCR·복잡한 문서는 결과를 원본과 대조해야 합니다. 코드 서명 인증서는 적용되지 않았습니다. 모든 환경·미래 입력의 무결함이나 경쟁 제품 대비 속도를 보장하지 않습니다.
