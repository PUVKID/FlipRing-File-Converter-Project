# 🔄 1.10 개발 이력과 1.11 배포 변경

## ✨ 1.11.0 · 간단한 기본 화면과 문서 변환

파일 선택 → 형식 선택 → 변환으로 시작하고, PDF·OCR의 세부 설정은 고급 옵션에서 펼칩니다.

HWP·HWPX 읽기·다른 형식 변환을 유지하며 DOCX·TXT·HWP5·HWPX에서 HWP·HWPX로 저장하는 제한된 로컬 변환을 제공합니다.

단순 문단·굵게/기울임·직사각형 표·PNG/JPEG 그림을 다루고 지원하지 않는 구조는 거부합니다.

HWP5 저장은 실험적이며 HWP3 출력은 제공하지 않습니다.

병합·중첩 표, 수식·주석·필드와 떠 있거나 회전한 그림 등 지원하지 않는 복잡한 구조는 거부합니다.

모든 HWPX 사용자 부품·글꼴·쪽 배치의 완전 보존이나 외부 뷰어 시 각 일치를 보장하지 않습니다.

HWP·HWPX의 PDF·Word 등 기존 읽기 변환과 Office 문서 변환에는 LibreOffice가 필요하며 HWP 읽기에는 H2Orestart·Java를 사용합니다.

초기 Excel 2007 Beta2 XLSB는 지원하지 않습니다.

일부 영상·오디오·문서 기능은 FFmpeg·Pandoc 등 별도 도우미가 필요합니다.

실행 파일과 설치 파일에는 코드 서명 인증서가 적용되지 않았습니다.

## 비공개 운영 기록의 비교 제외

`소스/검토기록.md`는 공개 대상에서 삭제했습니다.

이전 원문은 12701바이트이며 SHA-256은 `56046aa519af63aa6a2a6be3bce5f53f4dcbc7e4027a700fa93c1b0b4f3ff6fc`입니다.

비공개 운영 기록의 본문 재공개를 막기 위해 전체 비교와 현행 소스 비교의 해당 파일 구역만 제외했습니다.

삭제 사실과 원메타를 기록하고 다른 공개 파일의 코드·주석·공백·개행 비교는 유지했습니다.
