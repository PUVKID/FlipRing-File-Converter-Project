# 부드러운 디자인 수정

확인일: 2026-10-21. 작업: fluid-design-20261021.

사용자는 현재 흑백 디자인을 바탕으로 더 깔끔한 화면, 다른 글꼴, 딱딱하지 않은 움직임을 요청했다. 별도 차수나 새 제품 폴더를 만들지 않고 바탕화면 플립링 하나에서 갱신한다. 용량이 필요하면 기존 생성 실행·설치 파일을 정리하도록 허용했으며, 전체 소스·빌드 방법·설정·검증 기록·라이선스는 보존한다.

## 적용 방향과 이유

- 앱 안에서만 SUIT 글꼴의 보통·중간·약간 굵은 굵기를 사용한다. 기존 시스템 글꼴 대신 일관된 한글·영문 모양을 제공하기 위해 원본 TTF와 OFL을 동봉한다. 운영체제와 다른 앱의 글꼴은 바꾸지 않는다. PDF용 기존 나눔고딕은 유지한다.
- 흑백과 회색을 유지하고 강한 테두리와 과한 제목 굵기를 줄인다. 간격·정렬·컨트롤 크기를 통일하되 텍스트를 흐리게 만들거나 기능을 숨기지 않는다.
- 원형 메뉴의 등장·퇴장·선택 강조는 현재 화면 상태에서 이어지도록 한다. 빠른 재진입이나 선택 전환에서 시각 상태가 처음으로 튀는 현상을 방지한다. 클릭·드롭 영역과 메뉴 위치를 움직여 조작을 불안정하게 만들지 않는다.
- 버튼과 탭의 상태 전환에도 필요한 범위에서 부드러운 변화를 적용한다. 반복 애니메이션이나 상시 고속 타이머, 느려진 입력 처리는 추가하지 않는다.

## 유지할 기능

무료 배포와 제작자 PUVKID, 모든 기존 변환, PDF·한영 OCR·Word/Excel 내보내기, 한영 설정, 탐색기 Shift 드래그, 중앙 취소, 원본 보존, 트레이·자동 시작, 기록 왼쪽 더블클릭의 탐색기 선택을 유지한다. 인증·사용 횟수 제한을 추가하지 않는다.

## 완료 기준

글꼴 원본·라이선스·실제 Qt 선택 글꼴을 확인한다. 모션의 중간 상태, 종료와 재진입, 빠른 호버 전환, 고정된 드롭 영역을 회귀 검사한다. 기존 GUI와 PDF/OCR 검사를 실행하고 별도 검증자가 최종 파일을 재검증한다. 새 실행·설치 파일과 전체 소스를 같은 폴더에 제공하고 실제 Windows 화면 및 탐색기 동작과 소스 검사 결과를 구분해 기록한다. 모든 하드웨어의 일정한 프레임 속도를 보장한다고 표현하지 않는다.
