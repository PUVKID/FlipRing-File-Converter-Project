# 작업 원본의 공개 범위

이 폴더에는 현재 공개 제외 안내만 제공합니다. 이전에 포함됐던 작업 자료 622개는 운영 로그·실패 기록·실행 중간 자료가 혼재하여 현재 공개 사본에서 제외했으며, 로컬 원문과 개별 크기·SHA-256을 비공개로 보존했습니다. 이 안내를 해당 원문 코드나 새 제품 차수로 해석하지 않습니다.
