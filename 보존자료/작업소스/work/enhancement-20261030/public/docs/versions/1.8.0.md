# 1.8.0 · 고정 창과 세부 디자인

기본 창을 1080×780에서 1160×820 논리 픽셀로 늘리고 사용자 크기 변경을 잠급니다. 작은 사용 가능 화면에는 창 맞춤과 스크롤을 제공합니다. 메뉴의 선택선·본문 경계·프리셋·작업·출력·비교 영역의 제목과 구분을 보강하고 이미지·SVG의 고배율 렌더를 조정했습니다.

상태 표시의 첫 애니메이션 틱이 늦게 시작되면 완료가 지연될 수 있는 기전을 제어 시험으로 재현했습니다. 400ms 단발 타이머로 유한 종료를 보완하고 숨김·재진입·모션 줄이기 동작을 검사합니다. 이전 실제 실패와 원래 420ms 기대 검사는 보존합니다.

## 검증과 공개 범위

구현·포장 준비 자료를 로컬에 먼저 기록하고 실제 검사·실행·설치·독립 검토 결과를 아래에 구분했습니다. 이전 1.7의 사용자 실제 탐색기·PDF 조작 확인과 이번 Qt 오프스크린 배율 시험을 구분합니다. 변환 엔진·검사기·7-Zip 바이너리 해시가 같을 때만 기존 266개 변환 기록을 재사용합니다.

실행 자산·모델·대용량 바이너리·개인 지침·메모리·원문 대화·운영 경로가 들어 있는 비공개 기록은 이 공개 사본에 넣지 않습니다. 로컬 전체 소스에는 실행 자산·법적 고지·빌드 방법을 보존합니다. 이전 공개 차수 파일은 덮어쓰지 않습니다.

## 확인된 검사 결과

- Qt 가상 화면 100·125·150·200%와 640×480의 다섯 조건에서 각 7개, 총 35개 검사가 통과했습니다. 소스 9파일, DPR, 사용 가능 화면과 실행 중 소스 불변을 보고서에 결합했습니다.
- GUI 85·PDF/OCR 28·일반 작업 20·PDF 편집 30, 총 163개 회귀가 부모 검사에서 24.479초에 통과했습니다. 이전 최소 960×680 기대는 새 고정 1160×820 요구에 맞춰 두 assert만 바꿨으며 나머지 바이트와 검사 ID를 보존했습니다.
- 작은 선택창의 이름 열을 최소 180으로 확보하고 마지막 열까지 가로 스크롤로 접근하는 것을 Qt 시험에서 확인했습니다. 파일·폴더 아이콘은 DPR 2 요청에 48×48픽셀/DPR 2를 반환했습니다.
- 독립 시각 검토는 최초 26장, 후속 40장, 선택창 보완 4장을 구분해 기록했습니다. 마지막 작은 화면 표본에서는 파일·폴더 이름을 읽을 수 있었습니다. 정지 렌더를 실제 OS 배율 변경·물리 Shift/OLE·화면 프레임 속도 확인으로 표현하지 않습니다.
- 모션은 400ms 기한의 종료 이벤트로 첫 틱 지연을 보완했으나, GUI 이벤트 전달이 늦어진 표본에서는 420ms 뒤에도 Running을 관측했습니다. 이전 실패를 보존하며 모든 부하의 엄격한 실시간 종료를 보장하지 않습니다.

실행·설치 파일 빌드, 실제 설치 종료0과 응답 창, 출하 625파일의 설치 폴더 일치, EXE 주요 12모듈과 납품 소스의 코드 객체 일치를 확인했습니다. 배포 1017파일의 SHA-256 목록을 생성했습니다. 최종 독립 검사도 기능 163개 26.359초와 배포 대조 2.860초로 통과했습니다. 원문 영수증은 로컬 검증 자료에 보존하며 커밋·원격 일치 결과는 별도 반영 영수증으로 구분합니다.

## 공백·개행 차이

실제 바이트 비교에서 pdf_panel.py는 1.7의 LF 1216줄에서 1.8의 CRLF 1231줄, ui_motion.py는 LF 781줄에서 CRLF 835줄로 바뀌었습니다. 두 파일의 전체 줄 차이에는 줄끝 변경이 포함되며 모든 줄의 기능이 바뀌었다는 뜻은 아닙니다. 공개 문서 생성·갱신에 따른 줄끝 차이도 전체 패치에 포함했습니다. 이전 원문은 history/1.7.0에서 그대로 보존합니다.
